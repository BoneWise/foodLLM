# 营养信息条件下的模型—脑表征对齐：结果说明

[项目首页](../README.zh-CN.md) · [图表复现](README.md)

## 问题与方法

研究考察营养信息如何改变模型的食物表征，以及这些变化与人类食物估值期间的脑表征如何对应。营养信息添加在模型输入端；人类 fMRI 来自原有的看图估值任务。

Qwen3.5-9B 的 32 层表征与 29 名参与者的单试次 valuation β 多体素模式进行 RSA。当前四营养分析使用 401 张图片范围，每个 ROI 共 11,207 条脑观测。每次输入一种营养属性，单位为 g/100 g。A 为主提示，B 为措辞变化。

| 条件 | 输入 |
| --- | --- |
| V | 图片与任务提示 |
| T | 图片、任务提示与该图片对应的营养值 |
| N | 图片、任务提示与无关文本；三套实现的 RSA 均值 |
| P | 图片、任务提示与错配营养值；五套实现的 RSA 均值 |

模型与脑 RDM 使用 1−Pearson 距离，同一参与者的可用食物配对通过 Spearman 相关进行比较。38 对 HCP 分区先分别计算左右侧 RSA，再取均值；原 vmPFC、lOFC、mOFC 三个 ROI 沿用双侧多体素定义，共 41 套区域结果。另有 5 组区域汇总。

四项差值分别表示：T−V（相对图片基线）、N−V（无关文本相对图片基线）、T−N（营养与无关文本）、T−P（匹配与错配营养）。

## 主要结果

- **蛋白质：** OFC 九区汇总及原 vmPFC、lOFC、mOFC 的全层 T−V 在 A/B 均为正；早中视觉均为负，高阶视觉随提示变号。
- **脂肪：** OFC 九区汇总、三个原 ROI 及高阶视觉的 T−V、T−N 在 A/B 均为正。20 个固定随机区域也呈现两项差值均正的全层均值。
- **碳水化合物：** OFC 九区汇总及两组视觉的 T−V 在 A/B 均为负；原 vmPFC、mOFC 为正。
- **纤维：** OFC 九区汇总及两组视觉的 T−V 在 A/B 均为负，原 vmPFC、mOFC 为正。两组视觉同时呈现 T−P 为正，即匹配条件较错配条件下降得少。

这些结果表明，营养输入对应的对齐变化具有区域、营养、层和提示依赖。T−P 的分布与 T−V、T−N 各有不同：例如脂肪在原 vmPFC 的 T−V 为正，而 T−P 为负。

## 结果的统计范围

当前结果为描述性分析，正式显著性检验与扫描结构敏感性分析尚未执行。全 32 层为主要展示范围，L17–32 为查看结果后选定的探索窗口。N/P 范围表示不同文本或错配实现之间的变化。

无关文本插入行的中位长度为 11 token，营养行为约 15–18 token。区域间的绝对 RSA 和跨人 RDM 一致性各有差异，解读区域变化时应结合[测量指标](../outputs/20260918_控制实验报告_v03/ROI_quality_summary.csv)。
