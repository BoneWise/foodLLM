# v06.1：先测量raw trial-β与模型的表征关系

日期：2026-09-16。根据用户本轮意见简化[v06](20260916_营养条件化模型脑表征RSA方案_v06.md)。**当前目标是验证输入与RSA计算流程、获得描述性结果；正式统计推断后置。**本版替代v06的默认执行顺序，旧文档、配置、数据和结果保留。

研究问题不变：正确匹配的kcal/100 g信息，是否使Qwen内部食品表征结构更接近固定的人类vmPFC结构，并优于图片及合理错配条件？本轮仅修改计划，未计算真实RSA。研究仍是已见MSE结果后的post-result follow-up。

## 2. 第一层：输入有效性，不增加β预处理

提取前／提取时只完成以下入口检查：

1. **Unsmoothed来源**：将β追溯到实际LSA的SPM输入及估计流程，确认未加入空间平滑；不能仅凭β文件名推断。
2. **ROI体素数与几何**：逐人记录支持mask体素数、空间尺寸/affine及与既有mask一致性；不按RSA效果调整ROI或新增数量门槛。
3. **固定体素身份与顺序**：每人的全部trial使用相同mask及同一索引顺序。
4. **Finite**：所有提取值有效；读取失败、NaN/Inf均记录定位。
5. **非常数pattern**：跨体素方差为0的trial无法计算相关；显式记录，不用微小常数补分母或悄悄删pair。
6. **对应关系**：核对subject/session/run/trial/image/β联合键；提取均值与已有ROI均值逐条一致。

若入口失败，定位并记录数据问题，不静默改mask、补值、另换距离或按模型条件单独剔除。修正若影响样本，另存新版证据。

这里的“raw β”指**已估计的LSA β在进入RSA前不再额外变换**，不是未预处理BOLD。既有[实际SPM审计](20260916_外置盘SPM复核与脑信号诊断.md)记录输入来自fMRIPrep的desc-preproc BOLD、LSA未额外平滑；本轮只复读该证据，未重新核验整个上游流程。pattern提取时须保存对应的来源证据。原作者另一套6 mm平滑参数调制流程不混用。

**不增加PCA、白化、session/run去均值、逐体素跨trial标准化、partial RSA或pair删除。**Pearson公式本身对每个向量的中心化不属于新增session preprocessing。

## 3. 第二层：先跑Prompt A，得到最直接的曲线

\[
D_s^{brain}(i,j)=1-r(\mathbf b_{s,i},\mathbf b_{s,j}),\qquad
D_{l,c}^{model}(i,j)=1-r(\mathbf h_{l,c,i},\mathbf h_{l,c,j}).
\]

\[
A_{s,l,c}=\rho_{Spearman}\left(D_s^{brain}[M_s],D_{l,c}^{model}[M_s]\right).
\]

使用非对角下三角、固定float64计算、Spearman平均秩处理平局。不将121,278个食品pair当独立观测。先构建29张脑RDM及A的224张模型RDM（7条件×32层）。已有模型缓存直接复用，无须重跑Qwen。

五套P先各自算RSA，然后：

\[
\bar A^P_{s,l}=\tfrac15\sum_{k=1}^{5}A^{P_k}_{s,l},\quad
\Delta_{s,l}^{T-V}=A^T_{s,l}-A^V_{s,l},\quad
\Delta_{s,l}^{T-P}=A^T_{s,l}-\bar A^P_{s,l}.
\]

不平均hidden states或RDM。保存五套P原分数，报告范围；五套P是固定错配实现，不增加人类样本量。

第一轮只报告：

- V、T、平均P的完整32层曲线；参与者等权均值。
- T−V、T−P曲线及逐人差值分布，明确报告效应量级。
- 五套P之间的分数范围，不能标为置信区间。

不先算p值、显著性星号、同时置信带或行为bootstrap。若用逐人曲线、分位数或范围展示差异，明确是描述性分布而非总体置信区间。不以曲线正向、平滑或出现预期峰值作为流程通过标准。

最低限度的数值验证仍保留：人工小矩阵距离/Spearman核对、ID重排一致性、非对角掩码、P先score再平均、矩阵对称与有限值。若RDM下三角本身恒定，Spearman同样无定义，应报告原因；不能仅因trial非恒定便假定所有score必然有效。这些是计算正确性检查，**不要求先实现推断覆盖模拟**。

## 4. Wanting和kcal：固定参考

493图现有可用评分均值H_i形成Dwanting(i,j)=|H_i−H_j|。与各层模型RDM比较，展示V/T/平均P曲线及五套P范围。它是一张固定群体行为参考RDM，当前不做行为bootstrap、置信区间或显著性家族，也不复制成29个独立结果。

Dkcal(i,j)=|kcal_i−kcal_j|。分别与各人的脑RDM按相同有效食品比较、与群体wanting RDM在完整493图比较；作为水平参考和描述性数值，不新建检验家族。T高于kcal参照不自动证明超越营养的独立信息或因果整合。

## 5. 第三层：session/run QC只报告，不自动修正

分别建立0=同次、1=不同次的session和run identity RDM，计算其与每人主脑RDM的Spearman相关；报告逐人score、同/不同组pair数与基本距离摘要。

**run身份必须用该参与者内session_id＋run_id联合定义**；不能把ses-01/run-01与ses-02/run-01当同run。session/run QC不改变主脑RDM，不用于按效果删人、删trial或删same-run pairs。

QC关联弱不等于证明没有扫描噪声或已经达到测量可靠性；关联明显时记录限制并评估后续敏感性，不凭“看起来高”自动执行修正。目前不设未经依据的异常阈值。

以下仅预留方法定义，**首轮默认不执行**：

| 预留敏感性 | 若后续决定执行时的方法 |
|---|---|
| Session centering | 每人每session在有效主样本trial内逐体素减均值pattern，再建完整脑RDM |
| Within-session-only | 从原始脑/模型RDM提取全部同session pair，合并后重新求秩并计算RSA |
| Exclude-same-run | 从原始RDM移除同一联合run身份的pair，余下pair重新求秩并计算RSA |

只有采集结构QC提示值得进一步调查时，再记录选择理由、所见结果及敏感性版本；不根据哪种处理提高T效应择优。敏感性不替换raw主结果。当前不预留自动白化、run去均值等额外分支。

## 6. Prompt B与正式推断后置

**B仍是既定稳健性检查。**A的数值、索引和输出完整性验证通过后，原样计算B的224张模型RDM及对应结果；不以A是否有正向效果来决定跑不跑B。A无效应、负效应或B更好都不改变A的主次地位。不重调距离、token或样本。

本轮正式推断设置为未定、未执行。v06的50,000 sign flips、64项maxT、10,000 bootstrap、studentized同时带及覆盖模拟不再是首轮任务或默认参数。也不在本轮改用cluster检验替代。

现在固定的统计原则只有：**人类推断单位是participant；主对比为T−V与T−平均P。**将来若开展跨层推断，再明确方法、校正范围、参数、区间及泛化目标，并如实记录选择时哪些RSA曲线已可见。不能尝试多种检验后仅保留显著者，不能把结果可见后的选择改称盲态预注册。未来若需要行为不确定性，应重新考虑参与者重采样并重建群体均值RDM，而非把pair当独立样本。
