## 1. 核心问题与贡献

> 在固定食品图片任务中，多模态模型不同深度的表征，对人类想吃程度和vmPFC反应的可预测性如何变化？内部表征是否比最终层及显式评分输出提供更多可利用的预测信息？

本研究的“对齐”定义为：冻结模型特征经过受限的监督线性映射，对留出图片或采集run中的目标产生预测。它不是原始向量相关、神经时间对应或模型与人使用相同价值机制的证明。

| 研究问题 | 分析与主要证据 |
|---|---|
| RQ1 人类欲求信息在哪里较易读出？ | 全部解码器层→人类逐图均分；嵌套选择的层与最终层、输出分布基线比较 |
| RQ2 vmPFC预测信息的深度分布如何？ | 相同层→逐被试ROI平均单试次β；独立选择与留出评估，不借用全数据脑峰值 |
| RQ3 行为有用的层是否也有神经增量？ | 只由允许的训练行为选择层，再检验该层对未见脑试次是否超出输出与固定控制基线 |

先检验预测分布与内部—输出差距，不预设中层峰值必然出现。论文主图为两条曲线＋嵌套比较＋行为选层的神经增量。营养信息操纵、多模型、多prompt、视觉塔逐层扫描、全脑、逐体素编码及RSA不纳入本版。

## 3. 一次提取，固定读出位置

### 3.1 模型任务

一个支持图像输入、逐层访问和答案概率的开放权重VLM；检查点与精度待选。唯一输入条件为图片＋固定欲求问题。任务明确预测原人类场景中的想吃程度，不能混成模型自己是否有食欲或一般健康评价。日文原始等级标签、提示语言和chat template在正式运行前核实冻结。

每图独立上下文，不提供人类评分、营养标签、图片ID或食品名表格。不开启生成解释或思维链后再提取特征；不按研究目标上的分数挑模型或prompt。

### 3.2 层与token的定义

主分析只用**能够访问图像上下文的语言解码器各block输出**，全部层采用同一位置：已输入图片与问题、尚未生成答案时，最终非padding提示token。若模板插入assistant起始标记，实际位置按token序列记录，不凭可见文字猜测。

- 定义h_l为第l个block之后、模型最终归一化之前的该token残差流，l=1…L；各层维度相同。
- 必须核查所选实现的hidden_states语义：某些接口最后一项已经经过final norm，不能把它与前面block输出混为同一系列。用hook或可验证接口统一抓取。
- 最终归一化后的head输入单独保存为终端检查点，不冒充额外decoder层；它是防止最后一层下降由接口差异造成的必要对照。
- 仅保存该token各层向量、合法答案概率及推理元数据，不保存所有图片token×层激活。视觉编码器与连接器不并入横轴。
- 检查各层随图片变化、样本顺序、padding和单图/批量提取的一致性；用少量预指定图做接口核验，不根据H或β相关选接口。

### 3.3 足够强的输出基线

保存合法1–4答案概率p，并定义期望评分m=Σk·p_k。记录合法答案总概率质量、tokenization与序列概率规则；不能仅保留argmax四分答案。

行为侧报告三项输出基线：原始m（描述）；训练集标量仿射校准m（辅助）；**p的三个独立分量进行线性读出（主输出基线）**。最后一项避免把高维隐藏层只与过度压缩的单个数字比较，但仍不是整个词表、任意提示或非线性输出利用的上限。与隐藏层一样，只用训练目标拟合和调参。

脑侧直接以原始p拟合β，不使用先拟合人类H得到的校准值。

## 4. 统一读出方法与指标

所有层统一训练集逐维标准化＋ridge（岭回归）；不按层切换PCA、PLS或token池化。主分析不作PCA，避免额外维度选择。零方差维度按固定规则置零，保存有效秩和被删除维度计数。

建议损失定义为 `mean((y−b−Xw)^2) + λ||w||²`，截距不惩罚；λ网格固定为10的−6到6次方共13个值。使用按误差汇总的内层选择，完全并列时选较大λ。若接口采用求和损失，相应alpha=训练样本数×λ，不能混用定义。网格是工作稿建议，需在正式冻结时确认。

各层共享同一训练／测试观察、预处理、内层折及λ网格；λ可由各层的内层训练选择。相同算法和维数不保证相同有效复杂度，因此记录有效自由度／秩，结论限定于此映射族。层末精度或归一化差异不能冒充信息损失。

主误差为汇总留出预测的MSE。画曲线可用相对训练均值基线的交叉验证预测增益：

`Q² = 1 − Σ测试(y−预测)² / Σ测试(y−对应训练集均值)²`。

它是明确定义的留出技能分数，可能为负，不是样本内解释方差。不要平均小测试run的R²。比较模型时用同一观察上的误差差值；Spearman、Pearson为辅助，不以挑选最高相关替代主指标。

## 5. RQ1：人类wanting逐层曲线

1. 568图按食品名称／近重复组做建议的5个外层折；每个外层训练集内再做4个分组内层折。种子和fold文件待冻结。
2. 每一层仅在内层调λ，再用外层训练图拟合，预测外层测试H。得到所有层的独立留出预测，画W_l曲线。
3. 在同一内层预测中联合选层与λ，形成l_W；只在外层测试图比较该选择程序与最终block层、主输出分布基线。终端归一化后特征作接口稳健性对照。
4. 报告各外层l_W分布；不把完整测试曲线最高点拿来另做未经校正的“最佳层”检验。

全部H来自当前群体，研究目标首先是这29人的共同欲求。若进一步声称对新被试的个体欲求有效，需要另设被试留出任务；不由本版逐图均分结果推出。

## 6. RQ2：vmPFC逐层曲线

逐被试预测ROI平均β，主外层为完整run留出，训练run内建议做4折按run分组的内层验证；每层、输出基线、最终层共享完全相同划分。

为避免同名食品视图跨脑训练／测试，在每个外层先取测试run中的食品组，移除其他训练run中属于这些组的试次；内层同样按验证run的食品组清除训练重叠。这是带食品组排除的run留出，不是随机拆试次。各折剩余样本数量需在冻结前检查，遇到不足时先修订统一规则，不靠换成有利划分补救。

每层直接 `h_l → B_s`，不经过人类wanting读出。独立的脑内层选择l_B及λ，只在外层测试比较选择程序与最终层、输出分布基线。汇总每人全部测试误差后，等权汇总参与者，形成B_l曲线和配对差值。

所有标准化、目标尺度处理和监督拟合都只用训练run。不对测试run用其自身β均值／标准差进行目标标准化以改善预测；ROI支持集若用全体run的采集覆盖信息定义，需明确是预先无模型效果筛选的质量步骤。脑混杂处理须先核对既有LSA，不能事后添加有利的去噪。

ROI质量差时不能通过改坐标、缩ROI或筛“相关更高的人”挽救曲线。不要求同人同图重复的可靠性方法才适用；跨人一致性不能冒充个体重测可靠性。

## 7. RQ3：用行为选层，检验神经增量

两条曲线相似仅作描述。更强而可执行的连接检验如下：

对目标被试s的每个脑外层折：

1. 固定完整测试run及其所有食品组；从全部上游行为选择中排除这些测试组，包括其他人的同图评分。
2. 使用其余28人的评分构成H_{−s}，且仅在当前允许的脑训练图片中，以分组内层验证选择wanting最优层l_{W,−s,train}。不使用s的任何评分或外层测试脑反应；并列选预定较浅层。
3. 冻结这个层的身份。用其**原始h向量**在目标人的脑训练run拟合增量模型；不把经过H训练得到的标量预测或拟合系数传入脑模型。因此不需要为脑训练试次再构造两阶段wanting预测。
4. 在脑训练集内调脑ridge λ时，行为选层也应在各脑内层训练部分重做，排除内层验证食品组；不能让内层验证图片的H参与这一特征选择。
5. 外层测试仅比较以下两个模型，使用完全相同有效试次：

```text
基线：β ~ C + 输出概率的3个独立分量
增量：β ~ C + 输出概率的3个独立分量 + h_(行为选层)
```

C预定为red、green、blue、object_size、log1p(grams_total)、kcal_100g，现有568图均完整。它们控制有限的图片颜色、份量和参考热量，不构成穷尽的视觉／语义控制。

基线低维项和截距不惩罚，新增h用单一ridge惩罚；训练折内联合估计，不用全数据先残差化。基线与增量共享所有C；这是一个固定辅助控制分析，不额外扫描多套营养模型。

若该检验阳性，可以说“由人类欲求选出的层，对留出vmPFC反应提供超出指定输出及控制的预测信息”。**它仍不证明同一神经元、同一线性方向或同一种价值代码同时预测H与β。** 若要检验同一wanting读出方向的神经作用，需恢复更复杂的两阶段交叉拟合或独立行为训练数据，本版不追加该研究问题。

## 8. 层扫描、统计与结果判读

### 8.1 五项预定汇总比较

A：wanting内层选层 vs 输出分布；B：wanting内层选层 vs 最终block；C：脑内层选层 vs 输出分布；D：脑内层选层 vs 最终block；E：行为选层的神经增量 vs 其控制基线。

以误差降低为效应，方向可正可负，不只报告阳性。建议五项作为同一个确认性家族，使用Bonferroni调整的双侧99%区间控制家族错误率，并同时给95%估计区间。预注册前用无信号模拟验证具体重采样实现的覆盖率，不能直接对CV折或层数做t检验。

- 行为重采样食品组，重新拟合标准化、λ、选层及输出基线，重复组保持在同一折；区间条件于当前人类均分目标。
- 直接脑曲线／对比按参与者重采样，整条层向量一起保留；推断首先条件于当前刺激集。run或试次不充当参与者。
- E的行为训练在不同目标人之间共享评分，不能直接把其29个差值当独立观测套普通t检验。参与者重采样需重建H_{−s}及选层／拟合，目标人的所有重采样副本都排除于自己的上游训练；该程序的覆盖率需先模拟验证。若尚未完成验证，E只报告估计与明确标记的探索区间，不升级为确认性阳性结论。
- 图上逐层点用于呈现完整轮廓；若添加逐层显著性标记，使用保留层间依赖的同时置信带，不逐层未校正检验，也不按单个测试峰值定位精确层号。

两条平滑曲线的层点高度相关，`corr(W_l,B_l)`只作描述，不能把L层视为L个独立样本计算常规相关p值。行为和脑曲线的外层划分不同，也不能把各自最大Q²的绝对值作同尺度心理量比较。

### 8.2 允许的结论

| 结果 | 可以说 | 不能直接说 |
|---|---|---|
| 中层优于最终层 | 在固定读出族与样本规模下，中层的预测信息更易利用 | 后层删除了所有相关信息 |
| 隐藏层优于输出分布 | 固定任务的输出分布未达到该监督隐藏读出的预测水平 | 模型无意识地想吃／所有输出方式都无法恢复信息 |
| 两曲线峰区接近 | 对行为与脑有用的深度区间相近 | 同一价值代码或大脑处理阶段已被定位 |
| 行为选层神经增量阳性 | 行为有用层具有超过指定基线的神经预测价值 | 该层等同于vmPFC，或证明人类式价值计算 |
| 某端阴性或峰不稳定 | 当前测量／映射下未获得稳定证据，结合区间报告 | 原模型内部不存在欲求信息 |

研究不以“中层>最终层>输出”全部成立为成功标准。若只有wanting结果，按行为表征研究报告；若脑区间很宽，明确神经证据未定，不能改用RSA寻找阳性。
