## 2. 发现的实质问题：两个 valuation 超出扫描结束时间

以下两个 run 都有 **655 个 volume × 0.8 秒 = 524 秒** 的名义采集时长。它们的最后一个有效 valuation 尚未结束，采集就已经终止；后续评分／反馈发生在采集结束后。

| 参与者／session／run／trial | 图片 | valuation 时间 | 采集结束 | 当前 vmPFC β |
|---|---:|---|---:|---:|
| sub-002／ses-01／04／48 | 443 | 522.444–526.448 秒 | 524.000 秒 | **−61.0269** |
| sub-002／ses-02／04／48 | 43 | 521.744–525.749 秒 | 524.000 秒 | **−16.6344** |

相应估值区间只有约 38.9% 和 56.3% 落在名义采集时间内；更关键的是，延迟的血流响应大部分没有被记录。对应设计列范数分别仅约 0.00148 和 0.0140，SPM 的 β 估计方差因子分别约为同 run 目标中位数的 **46 万倍**和 **8,489 倍**。这里比较的是设计中的方差因子，不是直接测得的 ROI 标准误。

它们有有限 β、列名也正确，但这不足以证明 β 有足够估计精度。之前的入口条件确实漏掉了采集覆盖这一维度。

**影响有多大：** 两个试次都属于 493 图主样本。它们仅占 13,767 个脑观测的约 **0.0145%**，在原 A／食品留出共同脑基线中却占按原参与者等权规则汇总的测试 MSE 约 **11.071%**；全 568 图中为 **9.933%**。这些百分比是对原预测固定不变时的误差贡献分解，不是删除后的误差改善量。

另外，所有纳入 valuation 中，结束后剩余采集时间小于 4／8／16 秒的分别为 4／6／12 个，均包含上述两个试次。这些仅作时间覆盖描述；本轮没有把 4／8／16 秒选成新的剔除门槛。完整看完 valuation 也不自动保证 HRF 尾部覆盖充分。

## 3. 时间窗敏感性：仅去掉两个脑观测，重新拟合

这是结果可见后、由客观采集覆盖问题触发的诊断性敏感性分析，**不是对主分析做静默覆盖**。

- 只在副本中将两个不完整试次的脑目标设为缺失；29 人均保留，不剔除 sub-002，也不改变 sub-016。
- 两个行为评分仍保留，食品组、折号、营养 P、模型特征及所有上游 wanting 读出不变。
- 对受影响的 sub-002 重拟合每层／条件／提示的脑模型，包括食品×session 留出；其余 28 人的预测沿用并核对。
- 主脑试次变为 **13,765**，全样本脑试次 **15,867**。这只属于本次敏感性副本。

主提示 A，493 图，32 层平均：

| 指标 | 原分析 | 去掉两条脑观测并重拟合 |
|---|---:|---:|
| 食品留出共同基线 MSE | 2.56291 | 2.26626 |

| T 对 P 的相对误差改善 | +0.0133% | +0.0161% |

## 4. 人类 wanting→同阶段 vmPFC 正对照

诊断目的：检查现用 β 是否能呈现人类行为价值相关信息。它没有使用 LLM wanting 分数，而是在训练食品上拟合“基线＋本人实际 wanting”或“基线＋其他人的同图均分”，在留出食品评估。

**测试食品的人类评分在这里是有意提供的解释变量**，所以这是行为—脑正对照，不是仅看图的模型预测，也不是公平比较人类与模型优劣的独立实验。采用原食品折、训练内标准化及 OLS，报告描述性误差，无 p 值或总体区间。

### 描述性关联

去掉两个时间窗不完整的脑观测后，去除各 run 均值的“本人 wanting—β”相关：

- 568 图：参与者相关系数中位数 **r = 0.0596**，25/29 人方向为正。
- 493 图：中位数 **r = 0.0491**，25/29 人方向为正。

这支持存在较小的正向关系；这些相关系数使用所有可用试次作描述，不是留出预测指标，也不构成重测可靠性估计。

### 留出预测

下表以和主提示 A 一样的共同脑基线比较，正值表示增加人类评分后误差更低：

| 样本与验证 | 本人 wanting：原数据 | 本人 wanting：时窗敏感性 | 他人均分：时窗敏感性 |
|---|---:|---:|---:|
| 568 图，食品留出 | +0.1077% | **+0.3025%** | +0.1181% |
| 568 图，食品×session | −0.1829% | **−0.1124%** | −0.0678% |
| 493 图，食品留出 | −0.1382% | **+0.0032%** | +0.1160% |
| 493 图，食品×session | −0.3619% | **−0.2325%** | −0.0624% |

还分别检查了仅 run／全局截距基线与 B 提示的完整基线，没有只保留最有利的一种。人类评分的留出预测收益整体较小，跨 session 也未稳定改善。不能直接把当前微弱神经结果归因于 LLM，也不能据这次描述性正对照宣称 vmPFC 完全没有价值信号。

## 5. 其他设计质量发现

### 干扰项冗余

234/346 个一级 GLM 有秩不足，涉及重复的 `motion_outlier`、`fd_spike` 或 `non_steady_state_outlier` 列。所有目标 trial 的零空间分量均接近数值零（最大约 9.58×10⁻¹⁵），对应参数可估计性投影误差最大约 1.79×10⁻⁹。未发现 valuation 目标因这种冗余而不可识别。

这与之前“低维脑预测 OLS 无秩不足”不是同一检查：这里检查的是生成单试次 β 的一级 SPM 设计矩阵。未来整理 GLM 时应去除重复干扰列，但不能预期仅去重就改善目标 β 或解释全部弱预测。

### 阶段相关和单试次精度

- response 与 feedback 设计列高度相关，跨 run 中位数 r ≈ **0.9894**；分列建模不意味着两个阶段完全独立。
- 目标列的无中心化设计方差膨胀指标中位数约 1.94；37 个试次超过 10，2 个超过 100。这些仅是诊断参考数，不是自动 QC 门槛。
- 这种膨胀指标不能独自发现采集末尾的近零设计列；上述截断试次反而需要结合绝对估计方差因子和采集覆盖识别。
- SPM `Bcov` 表明同 run 不同食品折的部分 trial β 估计误差仍相关；各 run 的最大跨食品折绝对误差相关，中位数约 0.570。该数字是**每个 run 内最大配对值的中位数**，不是所有配对的平均相关，也不是测得的神经相似性。这支持继续保留食品×session 检查。

### 与原作者价值效应分析不等价

当前实际 LSA 输入为 fMRIPrep 的 `desc-preproc_bold`，LSA 脚本没有额外空间平滑步骤。原作者复现流程另有 **6 mm FWHM 平滑**，并估计 valuation×rating 参数调制效应。单试次 β 的留出预测与原作者的参数调制对比在估计器、预处理步骤和检验目标上均有差异；不能用本轮弱预测直接声称未复现原作者结论，也不能据此自动更改平滑、ROI 或阶段。

## 6. 当前判断与建议顺序

1. **β 阶段选择正确，逐试次与图片连接没有错位。** 实际 duration、HRF 与 β 数值已经核实。
2. **脑数据质量入口需要补上采集覆盖与估计精度。** 现有原脑结果含两条采集不完整试次，解释时须带上该限制；本轮敏感性显示主要神经增量判断未反转。
3. **先完善神经测量，再扩展 LLM 假说。** 依据采集和设计质量制定明确、可复现的脑 QC 规则，说明其发生在结果可见之后，不按模型效果选择门槛；保留原数据与全部敏感性结果。
4. **随后核对原作者人类价值分析作为方法参照。** 将其参数调制分析和当前单试次预测区分开，评估 ROI 均值是否足以回答我们的问题，再决定是否需要空间模式分析。

本轮未覆盖原始 BOLD 内容的完整哈希、全部预处理质量或正式重测可靠性；无正式统计显著性声明。没有删除历史数据，没有重估或覆盖外置盘 GLM，没有按旧二分类质量标签筛人。
