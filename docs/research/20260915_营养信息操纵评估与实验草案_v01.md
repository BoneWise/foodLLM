## 1. 总体判断与研究问题

意见中最有价值的改进，是要求营养提示后的预测不仅优于图片基线，还要与“图片预测＋原始营养数值”的统计模型比较。这个对照应保留。

但“超过线性营养基线 → 发生人类式价值整合 → 纠正视觉营养误判 → 更接近人脑机制”不能由预测增益直接推出。建议主问题先写为：

> 向同一模型提供与图片对应的参考营养信息，能否改善其对原图片任务中人类欲求的预测？这种改善是否超过数值／语境控制及预定的统计组合基线，并延伸到 vmPFC 反应？

这与前一版问题有区别：前稿主要问内部读出是否优于显式输出；本分支问**改变可获得的营养信息，能否改变预测表现**。建议将其作为一个受控的扩展模块，先以输出为主要测量，内部表征沿用既定层作次要检验。

## 2. 需要改正的四个解释跳跃

### 2.1 营养字段是参考估计，不是化学实测真值

当前使用的原 Food-Pics 1–568 图，营养与热量由研究助理依据食品数据库和包装信息估计；原论文同时提供每 100 g 与图示整份值。宜称“对应图片的数据库参考值”，不称无误的真实含量。[Food-Pics 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4067906/)

模型获得某个参考数字后表现更好，不等于模型此前对营养的估计错误。数字也可能改变注意、健康联想或目标理解。

### 2.2 超过线性相加，不足以证明情境整合

M_visual 是高维图像信息压缩成的评分。M_nutrient 超过 M_visual＋N，可能来自简单的数值非线性、量尺变化、类别线索被重新唤起，或不同压缩／正则化。结论必须限定为**超过指定基线的预测增益**。

若要讨论情境依赖，补充一个预定、低复杂度的非线性／食品类别×营养对照。超过它仍不等于排除了所有其他解释，也不能证明模型和人使用同一种整合机制。

### 2.3 “评分变化解释脑残差”不是第三项独立证据

令 X 包括控制项、M_visual 和 N，D=M_nutrient−M_visual。因为 X 已包含 M_visual，在线性模型中：

```text
X + D 与 X + M_nutrient 张成同一个预测空间。
```

在相同数据、包含截距且无惩罚的线性拟合中，两种写法给出相同预测。因此 D→残差可以帮助展示增量来自哪些图片，但不是比联合回归更强、独立的第三次验证。

若使用 Frisch–Waugh–Lovell 残差写法，需要同时将脑结果和 D 对相同 X 残差化。仅去除脑结果中的 M_visual，再让原始 D 去解释残差，既遗漏 N，也不等价于完整条件回归。训练、残差化、测试严格分开；普通 ridge 惩罚不具有这种任意重参数化等价性。

### 2.4 现有人类没有接受营养提示

模型端可以操纵输入信息；现有人的评分和脑数据来自仅看图条件。模型提示效应可归因于该输入操纵，但不能据此说“给人营养信息改变了 vmPFC”，也不能识别人的营养信息整合因果机制。

“脑预测改善、欲求预测不改善”首先是一种结果分离；视觉／类别共变、量尺和噪声也可能解释它。不能直接命名为“无意识营养价值”或推出从营养到脑再到意识报告的通路。

## 4. 推荐的最小实验：一个营养属性，四类输入

### 4.1 任务固定

仍预测原实验人群仅看图片时的想吃程度，而非模型自己的食欲，也非人类得知营养后的评分。所有条件使用同一个冻结模型、相同图片、同一日文主问题和输出格式。具体日文标签仍待原始材料核对。

所有条件的共同说明应交代：参与者遵循原任务的禁食要求、只看食品图片、没有看到营养标签。模型得到的补充资料用于预测这些既有条件下的评分，不用于想象一批已经读过标签的人。

每次推理使用独立上下文；前一条件的答案、模型估计、真实参考值和人类标签不带入下一条件。可预先交错条件运行以便审计；固定检查点和解码规则。重复随机种子不是新增人类样本。

### 4.2 输入条件

以下以脂肪为例，数值仅为格式示例：

| 条件 | 同图额外输入 | 用途 |
|---|---|---|
| V：视觉基线 | 无营养信息 | 测量原始表现 |
| T：对应参考值 | 脂肪含量：18.4 g / 100 g | 测量提供匹配资料的影响 |
| P：错配参考值 | 同样字段、格式、单位，数字来自其他图片 | 区分数值与图片匹配的作用和提到营养本身的作用 |
| I：无关数字 | 明确无食品属性含义的研究编号，数字长度与分布尽量匹配 | 检查额外文字和数字的一般影响 |

最低限度保留 V、T、P；本稿推荐增加 I。I 不能单独替代 P，因为无关数字并没有控制“脂肪”这个词引发的语境。

P 在每种预先确定的置换中保留参考值的边际分布，以多个固定种子重复；例如五组是可讨论的计算预算，不是已锁定参数。不得看行为／脑结果后挑选最有利置换。记录因相同值或显示精度导致的实际未改变输入。

错配数字可能与食品身份明显冲突，降低表现也可能反映违背常识。预定同大类食品内置换或合理范围匹配作为敏感性检查，并报告其变化幅度；不能事后靠结果定义“合理”。共同样本、相同推理数量和不同置换间的不确定性都要保留。

四类输入固定资料位置、数字精度及共同问题，不用 high-fat／健康／不健康等评价标签。不同数字的 token 数未必相同，记录后做匹配核验。每 100 g 是共同基准量；脂肪用 g、能量用 kcal，不能为了“单位统一”把不同物理量写成同一单位。

### 4.3 主要数据与输出

先用当前 568 图、29 人、15,869 条评分的已准备输入；脂肪／能量字段完整。记录生成数字和合法 1–4 答案的概率／序列分数，采用预定的评分期望与输出分布对照。概率是模型生成分布，不能直接当人群评分比例。

每条件的预测表现可使用同类、同训练量的校准器，复杂度和选择均在训练内部完成。展示 D=M_T−M_V 时，使用原始共同量尺或同一个固定校准器；不要将分别校准后的差值当作纯粹的模型输入效应。

## 5. 三项主要检验：行为有效性、超出数值基线、神经扩展

### A. 参考信息是否改善人类欲求预测？

主指标建议为同一留出图片上的 MSE 差值：

```text
G_behavior = MSE(V) − MSE(T)
```

G_behavior>0 表示 T 更好。另检验 T 是否优于 P，并查看 I 是否产生类似改变。Spearman、MAE、预测方差为补充，不用多个指标分别寻找阳性。

V、T 等比较使用各自预定、同复杂度的输出处理。若 T 仅在原始输出更好、各自合理校准后无优势，优先解释为尺度／格式效应。若 T 与 P 同样改善，则缺少正确匹配参考值产生额外帮助的证据。

主要对比与置换汇总规则事先登记，适当处理多重检验；先报告每个效应及区间，不把任一 p 值当后续实验可否报道的唯一门槛。

### B. 改善是否超过直接使用营养数字？

对目标 Y（先为人类欲求，后为脑反应），设 Z 为预定共同控制，N 为同图参考营养数值，建立：

```text
F0：Y ~ Z + M_V
F1：Y ~ Z + M_V + N
F2：Y ~ Z + M_V + N + M_T
```

主增量是 F2 相对 F1 在留出数据上的误差降低。这样控制组和增量组使用相同的基础信息，直接检验 M_T 是否在该线性基线之外提供有用预测。

原意见中 `Y ~ M_T` 对比 `Y ~ M_V + N` 可以保留为实用的模型替代比较，但二者不是嵌套模型。不能假定测试表现必然满足 F0<F1<F2，也不能拿样本内 R² 的增加作为证据。

若准备使用“情境整合”这一解释，再设置一项有限的基线敏感性分析：对 N 的低自由度非线性项、M_V×N、固定食品类别×N 进行预定编码。采用与增量模型一致的训练／内层选择规则，避免用很弱的数值模型制造优势，也避免将一个过度灵活、训练不足的基线称为公平上限。

即便优势存在，也叫“超出预定组合基线的增益”，不把它定义为已证实的营养整合机制。Z 的范围与估计目标需写清；不同营养相互相关，控制或不控制其他营养回答不同问题，不能在全量结果上挑控制集。

### C. 这种增益能否延伸到 vmPFC？

在独立定义、通过质量审计的 vmPFC 中，以 ROI 平均单试次反应作为候选主读数；逐参与者拟合 F1 与 F2。Z 包括必要的图像及采集／试次混杂，并与已有 GLM 处理相容。每 100 g 含量与所示份量分开处理，不把密度解释为整份摄入量。

主比较仍是留出脑数据的误差差值或 ΔR²。D 的残差图作为同一检验的解释图；残差基线包含 N，不能额外将其包装为另一项独立神经证据。

若结论包括“数值与图片的正确对应带来的优势也延伸到脑”，必须在脑端预定比较 **F1＋M_T 与 F1＋M_P**，必要时加 F1＋M_I；所有模型的 F1 都保留同一套正确参考 N 和共同控制，使用相同测试折。行为端 T>P 加上脑端 F2_T>F1，不能替代这个直接脑比较。多个 P 置换按预定规则汇总，不能挑一个较差的 P 作为对照。

若脑端仅完成 F2_T 与 F1，结论只限于 T 条件预测提供神经增量，不声称已排除语境／数字效应对脑增益的解释。

脑检验能回答：参考资料辅助的模型预测是否更贴近原看图任务的脑反应。不能回答人的营养提示效应。若要后一结论，需要新增人类随机信息操纵实验；本轮不启动招募。

## 6. 如何避免两阶段预测和脑划分中的泄漏

冻结模型按预定输入一次性生成各条件输出／表征，不使用人类或脑标签，因此可以缓存全图结果，无需逐脑折重新推理。

所有使用标签拟合的操作，则必须遵守以下规则：

1. 行为模型采用固定的图片外层划分，近重复图成组；内层完成校准、读出及模型选择。
2. 脑模型优先完整 run／session 留出。该外层测试中的图片 ID，不能参与上游的人类评分训练／调参，即便评分来自其他人。
3. 如使用经人类监督校准或读出的特征，为目标参与者 s 建立脑预测时，建议从其余参与者构成人类训练目标。在外层训练集内部交叉拟合上游预测，再训练脑预测器，测试折完全冻结。
4. 不把先生成的全局 OOF 预测表直接切成脑训练／测试；脑训练特征的生成模型可能曾使用该脑测试折的图片评分。具体嵌套方案见[前一轮评估](20260915_精简方案可行性评估_v01.md)。
5. 未经人类监督的原始模型分数和参考营养字段可直接作为该脑折的固定输入。脑拟合、任何残差化与超参数选择仍仅使用训练脑数据。
6. 配对比较同一测试观察的误差；参与者、图片两种依赖均需纳入推断。交叉验证折、置换次数、提示重复都不是新增独立人类样本。

不通过该流程选择 ROI、最优营养、提示或层。ROI 质量审计需在不知道哪种营养产生最好结果时制定，脑 QC 如改变样本则单独记录，不反向修改既有行为口径。

## 7. 如果希望进一步主张“纠错”或“表征移动”

### 7.1 纠错需要额外的测量

在独立上下文中，先让模型仅凭图片估计同单位的营养含量 N_hat，记录它与参考值的差异。这是模型报告的估计，不直接等于隐藏信念。

可检验：参考误差较大的图，提供对应资料后是否更容易改善欲求预测。但这仍可能受食品类别等共同因素影响。

更有区分力的扩展是增加 **E：把模型自己的营养估计，以与 T 完全相同的字段和格式重新提供**。T 与 E 的比较有助于区分“提供一个显式营养字段”和“把其数值替换为参考值”。它不能完全消除注意或任务语境解释，且不作为最小主实验的必需环节。

合理范围内的同图反事实数值梯度可用于研究模型对数值的响应形状；其因果对象仍是模型输入处理，不是食物营养改变对人的生理作用。

### 7.2 内部表征保留一个预定层即可

为了延续原 representation–output 项目，可缓存同一个晚层、答案生成前、对应 token 位置的表征。原始 Δh 混合了资料含义、额外 token 和位置效应，不能仅凭范数或投影图称为“向人脑移动”。

两种读出回答不同问题：

- **固定原读出器跨条件应用**：更适合问既定欲求方向上的分数怎样改变，但受条件分布变化影响。
- **每条件以相同训练量重新拟合读出器**：比较该条件下可利用的预测信息，但性能变化同时含读出器重学，不能全归因于原价值方向的移动。

先固定其中一种为次要分析，不同时进行全层搜索和多套脑编码。本分支不以内部结果是否阳性反选层。

## 8. 先选哪个营养维度？

| 候选 | 定位建议 | 理由与限制 |
|---|---|---|
| 脂肪 g/100 g | 首轮操作验证建议 | 单维、字段完整、容易构造同单位对应／错配对照。选择依据是操作清晰，不是已证明其脑效应最强；健康与能量联想仍是竞争解释 |
| 能量密度 kcal/100 g | 可预先指定的后续验证，或以热量知识为问题时作主属性 | 与 Tang 的图片—WTP—vmPFC 问题最直接对应，但参考证据有限；它汇总多种营养，不能识别某个宏量营养的独立作用 |
| 脂肪＋碳水 | 独立的第二阶段信息组合实验 | 需要都不给、只给脂肪、只给碳水、两者都给；不是将乘积作为一个标签 |
| 蛋白质 | 次要候选 | 可提供不同营养的稳健性，但当前不宜扩大主检验数量 |
| 纤维 | 人机差异的后续候选 | 已看过人类负关联，不能作为全新确认性发现；缺失六图，无当前直接的纤维提示—vmPFC 依据 |

如果研究目的被最终定为“隐式热量知识”，能量密度作为主属性更贴题；如果目的是先建立单营养信息操纵的可靠流程，本稿倾向脂肪。**二者均需事先选定，不根据全量脑成绩决定。**

多营养比较应使用相同测试图片及规则；含纤维时共同样本为 562 图，不混用历史 560 图。每种营养信息的可推断程度、数值分布和语义不同，因此即使比较预测增益，也不能把名次当作生物学重要性排序。

### 脂肪＋碳水后续设计

```text
V：图片
F：图片＋脂肪
C：图片＋碳水
FC：图片＋脂肪＋碳水

信息提供交互：M_FC − M_F − M_C + M_V
```

这检验两种信息的联合效应。四点评分的边界和输出链接函数本身可产生非加性，需配套量尺敏感性分析。即使存在交互，也不是食物摄入的生理协同；DiFeliceantonio 的食品类别效应不能直接等同于此。

## 9. 推荐执行顺序与判读

1. 核对参考营养字段、原任务和输入格式；选择一个主属性、模型、提示、指标与划分。使用独立开发图做格式核验，不以脑预测选属性。
2. 完成 V／T／P／I 的固定输出生成，先检验行为预测及数值对应性的作用。
3. 检验超出直接营养数值及有限组合基线的增量。残差图用于解释同一结果。
4. 按预先规定的质量与可辨别性标准完成 vmPFC 扩展；采集块外层留出和上游标签隔离。
5. 依据第一阶段证据决定是否开展 E 条件、单层内部读出或脂肪＋碳水信息组合；新假设另建版本，不靠增加条件寻找阳性。

| 结果 | 首要解释 |
|---|---|
| T 优于 V，但不优于 P／I | 没有充分证据表明对应营养值本身产生了改善；检查语境／格式因素 |
| T 优于 V、P，但不超过数值组合基线 | 参考信息具有预测价值，尚无超出该统计组合的模型优势 |
| T 超过上述对照，并有脑增量 | 支持匹配营养资料辅助的预测增益及其神经相关性；机制仍待区分 |
| 仅脑改善、行为不改善 | 两种测量表现分离，报告噪声和混杂解释，暂不命名为隐式价值通路 |
| 均未改善 | 在预定任务、模型、属性与精度范围未发现益处；不代表人不利用营养或模型完全不含营养知识 |

最终建议：**保留“营养数值直接入模”的对照，增加同字段错配条件，将主要证据收敛为配对预测增益及其神经扩展；把纠错和人类式整合作为需要额外区分的解释。**
