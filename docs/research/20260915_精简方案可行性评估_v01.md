## 1. 结论

**建议以此为候选主框架，但修改核心问题的强度、输出对照和脑验证划分。** 缩减营养机制、提示操纵、多层搜索与 human-only residual 是合理的：它们并非检验同模型读出差距的必要条件。

| 方面 | 可行性判断 | 目前缺少什么 |
|---|---|---|
| 行为目标 | 已有数据支持群体层面的未见图片预测 | 原始日文标签及固定提示；不能外推到真实进食或所有人群 |
| 模型计算 | 冻结特征加 ridge，计算路径可行 | 具体模型检查点、图像处理、表征位置与运行环境 |
| 主比较 | 可以检验内部读出相对输出的预测增益 | 输出概率对照、严格嵌套验证、探针控制 |
| 神经验证 | 问题明确，但能否检测到增量尚不确定 | ROI 质量、单试次信号、预测量相关程度和可辨别效应大小 |
| 理论判断 | 阳性结果能支持有限的可读出信息差距 | 无法完整二分“内部没有”与“内部有但未使用” |
| 新颖性 | 存在发展空间，单独 internal > output 不足以保证 | 回应 CLIP 零样本／监督读出先例及近期脑编码研究 |

现有服务器曾验证有约 48 GB 显存，适合评估可容纳的开放权重 VLM。冻结提取后，重复的统计拟合不必重新运行大模型。但这不是对任意模型尺寸或精度的适配保证。科学可行性尤其是脑增量，不由硬件容量决定。

## 2. 核心问题需要改成可被当前实验回答的形式

原方案提出：差距主要因为内部没有形成价值信息，还是有信息但没有表达。这是有吸引力的动机，但当前实验只能对它给出**不对称证据**：

- 内部读出在未见图片上更好：支持所选表征中有超过指定输出基线的、可由该读出器利用的预测信息。
- 内部读出没有更好：可能是所选层、token 位置、线性读出器、样本量或正则化不合适；不能反推内部没有信息。
- 即使内部读出更好，读出器也接受了人类监督。通用食物视觉／语义特征经训练后可预测欲求，不等于模型已经形成了专门的、人类式价值变量。
- 校准与探针都只是在预先规定的函数类中寻找预测，不是测量所有可能输出方式的“最大能力”。

建议核心问法：

> 在固定的食物欲求预测任务中，同一多模态模型的预指定内部表征，能否在未见图片上，比经过合理校准的显式输出更准确地预测人类群体评分？若能，这项增益是否与 vmPFC 反应有关？

结论使用“在指定模型、提示和读出器下，存在额外可利用的预测信息”。避免“定位了差距的主要原因”“证明信息未被使用”“价值信息在内部更强”等超出比较指标的说法。探针容量与学到任务本身的区别已有方法研究支持。[Hewitt & Liang, 2019](https://aclanthology.org/D19-1275/)

## 3. 输出基线应保留少量但足够强的对照

只比较一个生成整数与数千维内部向量，可能把数字离散化的信息损失误写成深层的表征／表达差距。

建议保留以下层次，全部使用同一训练样本：

1. **原始输出**：实际生成的 1–4 分数，以及四个合法答案的概率期望。记录答案 tokenization、归一化和输出合法性。
2. **标量校准**：训练集拟合 a+bM；如增加单调校准，事先限定复杂度与内层选择规则。
3. **完整输出分布读出**：用四类答案概率，或等价的三个独立 log-odds，拟合低维正则化预测。这检查期望／最大概率数字是否丢弃了有用信息。概率不是人群评分比例。
4. **内部读出**：同模型、同提示、一个预指定的晚层表示，用 ridge 预测同一人类目标。

主要主张应建立在内部读出优于预先规定的较强输出对照之上。若需要在几种输出对照中选优，只能由训练内层验证选择；名称改为“预定义的最强输出对照”，不用“显式输出最多能解释多少”。

正斜率的线性校准不会改变排序，所以 Spearman 不能单独检验校准是否成功。建议一个主指标：配对测试图片上的 MSE 差；Spearman 为补充。另报 MAE／测试 R² 可帮助理解，但不把多个指标都作为独立的成功门槛。保留负的测试 R²，避免把训练拟合度当测试表现。

### 需要的最少探针检查

- 表征在答案生成前提取；明确层、最后输入 token 或其他预定池化方式。不能读取包含已生成评分的状态。
- 标准化、降维、超参数选择、输出校准均仅在训练内完成。
- 人类标签置换时重新拟合训练流程，检查预测是否超出偶然结构；它是零假设检查，不能单独证明价值特异性。
- 一个简单的食品类别／视觉特征读出对照，有助于说明探针是否只利用一般食物差异。更广的模型或层搜索可继续删去。
- 单一模型、提示、晚层可以作为主分析，但结论相应限定。没有层搜索的阴性不能被解释成整个模型无信息；一个备选层或等义提示只能是预定的稳健性检查。

## 4. 三个分析保留，但脑验证要重新组织数据划分

### 4.1 两阶段预测不能只靠“每张图都有 OOF 预测”保证安全

行为分析中，某图的预测没有用过该图的人类评分，这是必要条件。进入脑分析后还需要：**任何用于训练脑模型的上游预测，都没有借用外层脑测试图片的人类标签。**

例如，全局五折得到的 A 折预测可能由包含 B 折评分的模型生成。若随后把这些 A 折预测拿来训练脑模型、在 B 折脑反应上测试，B 折的人类评分已间接参与了训练特征的构造。单个 B 图自己的预测虽然是 OOF，整条链仍未实现测试图标签的完整隔离。

两阶段预测通常需先在外层训练数据内生成交叉拟合的一级预测，再训练二级模型，最后评价完整管线。这里是将一般原则应用到不同输出目标的本项目，而不是直接调用现成同目标 stacking 就完成分析。[scikit-learn 官方示例](https://scikit-learn.org/stable/auto_examples/ensemble/plot_stack_predictors.html)

### 4.2 建议的脑验证流程

对每位目标参与者 s 和每个外层脑测试折：

1. **先确定完整留出的 run／session**，记其中实际测试图片集合为 T，优先保持脑数据采集块独立。行为主比较可以继续使用公共图片折，但脑分支不强求同一套全局随机折。
2. 上游欲求目标由其余参与者的评分构成；从所有上游训练／调参中排除 T 中图片。排除 s 的评分使该分支更明确地检验跨人的共同欲求，减少同人行为与脑结果的依赖。
3. 在外层训练图片内再次划分，分别生成输出对照和内部读出的交叉拟合预测；用它们拟合训练 run 的脑预测模型。内层训练还需嵌套校准／ridge 调参。
4. 用外层允许的全部训练图片重新拟合一级预测器，为 T 生成 M_out 和 M_int；冻结脑模型后预测测试脑反应。
5. 对每人汇总所有外层测试误差，再估计模型增量及其不确定性。不同人共享图片和部分行为训练信息，因此群体推断也需考虑这种依赖，不能把全部试次当独立样本。

固定的图像预处理和冻结模型表征可以缓存；更换被试／折时重拟合的是小型监督模型。无需为每个脑折重新运行 VLM。该实现比三行公式复杂，但仍在精简项目的范围内。

若以后存在完全独立的人类训练集，且图像任务与目标可比，可以简化上游训练隔离；当前尚未建立这种独立训练资源。

跨被试与跨刺激泛化及不确定性的区分参考 [Schütt et al., 2023](https://doi.org/10.7554/eLife.82566)。本项目的具体不完整评分结构、两阶段预测和 run 划分需要验证，不能直接套用其 RSA 公式。

### 4.3 脑模型采用联合比较即可

在独立定义的 vmPFC 中，以 ROI 平均单试次反应为候选主读数：

```text
基础模型：B_s ~ C + M_out
增量模型：B_s ~ C + M_out + M_int
```

C 是两模型共享的少量预定控制：与估计流程相容的采集／试次混杂，以及必要的低层图像或类别控制。具体控制先核查既有 GLM，避免重复或不合适处理。只设一个主 ROI，不增加全脑搜索。

主要看留出脑数据上的误差差值或 ΔR²；增加变量通常会改善样本内拟合，因此训练 R² 上升不能作为神经验证。

InternalUnique 可用于说明或可视化，但没必要新增一套主检验。把 M_int 对 M_out 线性残差化后联合回归，在相同样本、包含截距、对应的无惩罚线性模型等条件下，可与原联合模型产生相同拟合。**正则化惩罚、非线性映射或训练测试处理改变后，不能无条件称等价。** 训练折的正交关系也不保证在测试折继续成立。

只保留联合模型更清楚。残差若计算，残差化映射必须仅由允许的训练数据估计。这里的“独有”仅相对于指定输出及线性关系，不表示不可由其他方法恢复的信息。

## 5. fMRI 是另一种测量，不是自动独立的价值真值

行为和脑数据来自同一批人、同一次任务及相同食物。fMRI 提供不同测量，但“独立人类价值指标”的说法过强。

vmPFC 信号还可能受与价值相关的图像语义、注意和试次噪声影响。预先独立定义 ROI、排除目标人的行为训练、隔离测试图片、加入有限共同控制，可以增强解释；它们不能把相关结果变成价值机制的因果识别。

推荐结论：

> 在预先定义的 vmPFC 中，经过人类行为训练的模型内部读出，相对于指定输出对照，对未见试次反应提供增量预测；它与该任务的价值相关脑反应相联系。

它不说明模型本身有脑样价值计算，也不证明新增信息不含视觉／语义成分。与之前的 human-only residual 问题不同，这次检验的是 **M_int 超出 M_out**；这个变化应明确记录，但无需恢复被删去的分支。

## 6. 当前数据是否够用？

### 行为／模型部分

568 张独立图片量级可以支持冻结特征的正则化预测尝试；29 人有助于估计群体均分，但不能把 15,869 条评分当成 15,869 张独立训练图片。原有半组 Spearman 中位数 0.835 是有利的初步信息，不是对探针增益或效应检验功效的保证。

高维 ridge 是否泛化取决于信号及正则化。近重复图片需分组，缺失评分按预定规则生成均分；训练规模敏感性可帮助区分稳定趋势与少量训练样本带来的波动。

### 神经部分

主要不确定性包括：vmPFC 局部信号、LSA 单试次噪声、两项预测高度相关，以及新增信息是否在该 ROI 中具有足够幅度。29 人并不自动保证可以检测到微小的条件增量。先做不依赖模型阳性结果的 ROI 质量审计，并针对可能的增量进行可辨别性评估。

行为排除规则不自动成为最终脑样本规则；脑 QC 如需排除，需单列依据及样本流程，不能反过来改写既有行为样本。当前无同人同图重复，不使用要求此类独立重复的可靠性或距离估计方法。

神经增量阴性时，区间很宽只能说未检出；只有足够窄的区间才能对某个事先定义的效应范围作限制。论文不应要求三个箭头都阳性才允许形成结论。

## 7. 新颖性与删减的取舍

支持从主线移除营养机制、信息操纵、多层扫描、human-only residual 和全脑探索。少量识别性对照与质量检查仍是主比较的一部分，不属于新增研究方向。

但删减之后，RQ1–RQ2 与已有 CLIP 零样本／监督食物评分比较的距离更近。[Kojima et al., 2025](https://journals.plos.org/digitalhealth/article?id=10.1371/journal.pdig.0001044) 因此必须写清：**生成式同模型、即时欲求任务、足够强的输出基线、未见图片泛化、具有严格隔离的神经增量**。不是换一个模型就自动构成充分新意。

2026 年 8 月的视觉语言脑编码预印本仍需要补读全文；目前仅已核实作者登记摘要，不能保证其补充分析没有进一步重合。[Marrazzo et al., 2026](https://doi.org/10.64898/2026.08.25.747006)

这是对贡献定位的判断，不是发表等级或录用概率预测。

## 8. 建议保留的最终三项分析

| 分析 | 主要对象 | 主比较 | 结果边界 |
|---|---|---|---|
| A1 输出预测 | 人类群体欲求 | 原始输出、标量校准、预定输出分布对照 | 衡量固定任务的输出表现 |
| A2 内部增益 | 同一人类目标、同一测试图 | 强输出对照 vs 一种晚层线性读出 | 检验指定条件下是否有可利用预测增益 |
| A3 神经关联 | 独立定义 vmPFC 的留出反应 | C＋M_out vs C＋M_out＋M_int | 检验内部预测超出输出的神经相关性 |

建议顺序：确定输出与表征接口及主指标；并行规划而非事后挑选 ROI 质量标准；冻结分析；完成 A1–A2；按已写明的条件推进 A3。若 A2 没有稳定增益，报告该范围内未发现差距，A3 降为事先约定的次要／探索分析，不通过临时换层和换提示追逐阳性。

**最终判断：三项分析的规模可行；原稿声称的二分机制结论过强。完成上述修订后，它可以成为一个目标集中、结论边界清楚的研究方案。**
