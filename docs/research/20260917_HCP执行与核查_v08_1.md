# HCP 区域比较：执行与核查 v08.1

## 范围与决定来源

本轮落实用户确认的 18 对 HCP 分区、36 个单侧提取及 3 个不变的旧 ROI 参照。四营养、401 图、A/B、32 层、V/T/P1–P5 均复用已有模型 RDM。只做描述性 RSA，不做显著性检验、模型推理、额外脑预处理或根据效果选择分区。

所有九个 OFC 分区及其左右侧结果完整保留。OFC 九区摘要是九个双侧分区分数等权平均；双侧分数是左右两次独立 RSA 的均值。不是先把左右体素或九区体素拼接，也不是外侧五区均值与内侧四区均值各占一半。

## 图谱版本与空间

- 作者仓库：[wayalan/HCPex](https://github.com/wayalan/HCPex)，固定提交 `6d4082fcbfdb6814fc21dff82ff90b6c4ae33f30`。
- 使用 `HCPex_v1.1/HCPex_2mm.nii`，只取约定的 36 个皮层标签，不使用新增皮层下区域。
- 标签直接匹配作者 `HCPex_2mm.txt`，再核对 `HCPex_LookUpTable.txt` 的左右后缀与世界坐标方向；不沿用其他 HCP 标签编号。
- 作者 v1.1 手册第 1、4、10 页明确图谱位于 ICBM152 2009c asymmetric。现有 β 与目标 T1 属于 MNI152NLin2009cAsym；源图谱和目标网格不同，按世界坐标最近邻重采样，不估计新的配准。
- 源网格 91×109×91，目标 97×115×97；源 x 轴递减、目标递增均通过 affine 处理，不能按数组下标直接贴标签。
- 已逐图查看 18 对分区的三平面叠加，未发现明显错位或左右交换。这是群体体积图谱，不是每位参与者的个体表面分区；不能声称获得同等个体边界精度。

来源文件、许可证、哈希、标签、空间矩阵及叠加图见 [图谱目录（本分享包未收录）](../../SHARING.md#未收录材料)。原版 AAL ROI 的既有空间转换保持不变。

## 输入质量与派生脑数据

- 29 人 × 36 单侧 = 1,044 个参与者—分区组合全部完成覆盖核查。
- 每个区域固定体素为该解剖分区与此人所有可用 run 分析 mask 的交集；跨 session 不改变 voxel identity。
- 固定体素数 68–1,674。覆盖率中位数 98.96%，最低 67.80%；8/1,044 个组合低于 80%。没有套用旧 vmPFC 球的 80% 排除标准。
- 助手在新 RSA 效果计算前记录的技术门槛：至少 3 个固定体素、所有模式 finite 且非常数、RDM 非常数。覆盖作为描述性质量指标，不凭效果或组间一致性删人。
- 401 图范围，每人 328–401 张有效食品，共 11,207 条试次/区域；沿用原两条脑试次排除，不补齐缺失，没有新增排除。
- 使用原始 valuation 单试次 LSA β。没有 session/run centering、白化、PCA、体素标准化或额外平滑。
- 读取每条 β 时，同时复核既有 vmPFC 体素 payload，逐值完全相同。36 区 RDM 与独立 SciPy correlation distance 全量核对，最大误差约 8.0×10⁻¹⁵。
- 记录提取 payload 的哈希，不宣称对外置盘所有完整 β 文件或 BOLD 文件作了全字节取证。

## RSA 与区域比较

每个区域脑 RDM 为 raw pattern 的 1−Pearson 距离。与缓存模型 RDM 的对应下三角作 Spearman。先在每位参与者内统一食品配对，再比较条件或区域；实际本轮 36 个单侧与旧三个 ROI 的逐人食品掩码完全一致。

分别保留：单侧分数、18 个双侧分区分数、旧三个 ROI 分数、指定组摘要及参与者内区域差值。P1–P5 先分别计算 RSA，再平均分数。

主要区域比较：九区 OFC 的增益减去四区高阶视觉的增益；早/中间视觉作次要比较。每一项均有 T−V 与 T−meanP、全 32 层曲线及预定全层等权均值。旧 ROI 不加入 HCP OFC 摘要。

Session 与 session+run RDM 只作采集结构 QC。另报告逐人脑 RDM 与其余参与者可用配对均值 RDM 的一致性；它不是重测可靠性，不用于按一致性排除或除以“噪声上限”。
