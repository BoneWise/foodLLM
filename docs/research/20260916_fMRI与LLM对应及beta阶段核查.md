# fMRI 与 LLM 如何对应：β 阶段与逐试次核查

**后续质量更新：** 外置盘实际复核已完成，发现两条采集不完整的脑观测，已保留原结果并单独重拟合敏感性；详见[SPM复核与脑信号诊断](20260916_外置盘SPM复核与脑信号诊断.md)。本文件下文保留当轮记录。

2026-09-16。针对用户提出的“fMRI 怎么和 LLM 对应、有没有对应好、使用哪个阶段 β”进行只读审计；没有重估 GLM、改变 ROI、清理样本或重跑研究效应。

## 结论

**当前使用的是每张图片 valuation（看图估值）阶段的单试次 LSA β，取 vmPFC ROI 内的平均值。** 阶段由原始事件、原 β 索引及建模源码一致确认；过去实际 SPM 审计核对过相应列名、onset 与无目标参数调制项。本轮所有本地逐试次、图片及数组对应检查通过。外置盘目前未挂载，本轮没有重新读取 SPM 或 β 体积；实际 SPM 的 duration 尚需补核。

“对应正确”和“模型能解释脑活动”是两件事。当前链条的 ID 对应没有发现错误，但现有神经预测未显示优于共同脑基线的平均增量，不能声称已取得良好神经对齐。

## 1. 使用哪个阶段

本地任务事件的每个有效试次都有四个阶段：

| 阶段 | 含义／事件标识 | 当前是否作为单试次脑预测目标 |
|---|---|---|
| valuation | 看图估值，约 4 秒 | **是**，每试次一个独立回归项 |
| rating | 评分阶段 | 否，建模代码合并为该阶段的干扰回归项 |
| response | 按键时刻，事件 duration 为 0 | 否，单独阶段干扰回归项 |
| feedback | 反馈阶段 | 否，单独阶段干扰回归项 |

源码 `select_nonmiss_target_rows` 只选择有效 valuation 行；`build_lsa_conditions` 为每个试次生成 `target_trial_XXXX`，直接使用该 valuation 行的 onset 和 duration。所有有效试次在同一个 run GLM 中同时估计，即 LSA。rating／response／feedback 分别作为跨试次合并的阶段回归项；不能假设这些阶段各自也有每张图片的独立 β 可直接替换。

源码规定 canonical HRF、不加时间／弥散导数，TR 0.8 秒，128 秒高通和 AR(1)。当前本地事件与原 β 索引的 valuation 时长逐条一致：最小 **4.001 秒**、中位数 **4.004 秒**、最大 **4.069 秒**。

β 是 GLM 对该事件响应的参数估计，不是“截出这 4 秒 BOLD 再求平均”。SPM 根据 onset／duration 构造刺激函数并结合 HRF 建模；血流响应存在延迟且会重叠。因此，阶段回归项分别建模不意味着估计无噪声、无共线性，也不能把不同 LLM 层解释为脑内不同秒数。[SPM 官方建模说明](https://www.fil.ion.ucl.ac.uk/spm/docs/manual/fmri_spec/fmri_spec/)、[HRF 与响应重叠](https://www.fil.ion.ucl.ac.uk/spm/docs/tutorials/beginners/haemodynamic_modelling/)。

### 与原作者分析的区别

当前目标列为 `Sn(1) target_trial_XXXX*bf(1)`。它不是原作者 GLM1–4 中的 `valuation × rating_value` 参数调制效应，也不是群体 t 图或对比图。原作者 ROI 位置被沿用，但预测目标来自我们的既有单试次 LSA 结果。目标 trial 列没有预先乘以人类评分；旧源码中虽然保留 `pmods_list` 变量和辅助函数，实际目标条件创建没有调用该辅助函数，过去的实际 SPM 核查也确认目标没有 pmod。

## 2. 一个可追溯的实际例子

`sub-001 / ses-01 / run-01 / trial 1`：

| 项目 | 实际值 |
|---|---|
| 食物图片 | image_id = 138，`0138.jpg` |
| valuation | 10.041 秒开始，持续 4.020 秒，14.061 秒结束 |
| rating | 14.061 秒开始，持续 0.860 秒 |
| response | 14.921 秒 |
| feedback | 14.921 秒开始，持续 0.500 秒 |
| 所取 β | 此 run 的 `beta_0001.nii`，对应 `target_trial_0001*bf(1)` |
| vmPFC 平均 β | −0.1311241388 |
| 当前数组位置 | 参与者第 0 行、图片第 137 列，均为零起始索引 |

该 β 对应图片 138 的 valuation 事件，不是图片 1。β 文件编号属于 **该参与者／session／run 的设计矩阵列号**，不作为图片编号使用。后续通过完整试次键找到 image_id，再连到模型图片与缓存。存在缺失试次时，更不能假设 β 编号始终等于 trial_id。

## 3. 当前脑与模型对应的量

```text
同一张图片 i
  ├─ 人类 s：valuation 单试次 β 体积
  │            → vmPFC 固定支持区内取均值 → B(s,i)，一个数
  │
  └─ Qwen：图片 + A/B 任务提示 + V/T/P 信息条件
               → 回答生成前最后 prompt token 的第 l 层向量，4096 维
               → 在 V 条件训练的 wanting 读出 → q(l,s,i)，一个数
               → 与共同基线一起预测留出食品的 B(s,i)
```

ROI 为 MNI **[−2, 40, −6]，半径 8 mm** 球。参考网格中有 272 个体素；每个人使用该球与其所有可用 run 分析掩膜交集作为固定支持区，覆盖率 94.49%–100%。对每幅单试次 β 在该支持区求均值，所以当前目标是**局部平均响应强度**，没有保留体素间空间模式进入脑预测。

q 的行为监督目标是其他参与者对同图的平均 wanting，排除目标参与者 s。外层测试食品完全隔离；训练食品的 q 再通过食品组交叉拟合生成。最后每个人分别用 OLS 拟合“共同基线＋q”，V/T/P 的脑回归系数可各自训练。共同基线包含正确能量密度、颜色、物体大小、份量、V 输出概率，以及主食品留出中训练估计的 run 截距。

因此，更精确的名称是**逐层 wanting 读出的 vmPFC 均值增量预测**。它不等同于直接 4096 维隐状态→体素模式的 encoding，也不是 RSA、全脑对齐或神经时间进程对齐。

两个对应边界必须保留：

- **32 层都预测同一个 valuation β**，层是模型处理深度，不是 32 个 fMRI 时间阶段。
- **V/T/P 都预测同一套仅看图的人类 β**；人类没有接受本项目模型端的正确／错误营养提示，不能把 T−V 称作人类营养提示导致的脑变化。

## 5. 是否已经“对应得好”

按现有证据分三层回答：

1. **数据连接：通过。** 本地事件、图片、试次、ROI 数值与模型输入的链条没有发现错位。
2. **测量含义：部分相符但较窄。** 回答前模型状态与人类估值阶段具有任务上的对应；当前检验的是由 human wanting 监督提取的一维读出能否预测 ROI 均值。不能据此检验所有隐状态信息或脑空间模式。
3. **预测表现：尚未证明良好增量对齐。** 前一轮 A 的 qT 脑模型比 qV 只改善约 0.0347%，而相对共同基线误差增加约 0.200%；目前没有总体区间。数据连接正确不能把这类结果升级为肯定的神经对齐结论，也不能由此排除其他表征中存在脑相关信息。

### 下一步建议，尚未执行

- 外置盘可用后逐条补核真实 SPM duration、HRF 基函数与阶段回归项，检查 valuation 与后续事件的设计相关及估计精度。
- 加入明确标记为诊断的 human wanting→同阶段 vmPFC 正对照，检查当前单试次 ROI 目标本身能否呈现预期的行为关系；这不是已完成的证据。
- 在判断需要体素模式分析或其他 β 阶段之前，先明确科学问题是 ROI 强度、wanting 通路还是完整表征相似性；不因当前结果较弱就直接换阶段或 ROI。
