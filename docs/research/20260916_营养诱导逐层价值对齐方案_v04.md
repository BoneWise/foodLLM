# 营养信息如何改变模型中的人类价值预测：逐层方案 v04

日期：2026-09-16。根据[最新送评意见](inputs/20260916_用户提供_营养诱导逐层价值对齐意见.txt)修订。用户要求按该意见调整计划；本版采用“营养信息操纵为问题、逐层对齐为方法”的工作方向，替代v03作为当前入口。具体模型、参数和质量标准仍为工作稿，尚未预注册或运行。

## 1. 核心问题与最小矩阵

> 正确匹配的参考能量密度，能否让模型内部由原始看图人类wanting定义的读出，更准确地预测未见食品的人类欲求？这种改变能否改善vmPFC预测，并随模型深度呈现可重复的分布？

| 项目 | 当前工作方案 |
|---|---|
| 自变量 | V图片＋问题；T图片＋对应kcal/100g＋问题；P图片＋合理错配kcal/100g＋问题 |
| 唯一营养 | 能量密度，数据库参考值kcal/100g，不使用整份热量 |
| 首模型 | 拟采用Qwen/Qwen3.5-9B后训练版，BF16，关闭thinking；revision与接口待pilot冻结 |
| 主表征 | 32个语言block，同一答案生成前token；终端归一化后状态单列接口对照 |
| 人类目标 | 已有29人的原始仅看图想吃程度，1–4分 |
| 主读出 | 每层仅用V训练；冻结标准化、截距和权重后用于V/T/P |
| 脑输入 | 严格隔离训练后的wanting预测标量，不以任意高维hidden→β作为主结果 |
| 主泛化 | 全局食品组留出，各人分别拟合脑映射；同时保留采集块独立性检查 |
| 当前不追加 | 第二模型、LOSO脑映射、全脑、RSA、多营养、多prompt、表征因果干预 |

RQ1检验营养诱导的wanting预测改善；RQ2检验经wanting定义的信号能否改善脑预测；RQ3描述这些改善的深度分布。不要将“哪层最高”单独当成理论问题。

**人类在原实验中没有看到营养标签。** 本研究操纵模型获得的侧信息，目标仍是原始仅看图的人类反应；不检验人类标签效应，也不声称模型复制人类的营养整合机制。

## 2. 条件与现有数据：重新启用P准备

沿用[数据核对报告](20260915_现有数据与精简方案对照.md)：29人、568图、15,869评分；能量密度全覆盖；79个重复规范化食品名称组涉及217图；sub-016保留。数据不重清理，原始营养和类别不覆盖。

### 主样本与错配

现有粗类别无法直接保证P合理。按大类和加工标记寻找不同数值的试行规则下有6图无候选；水瓶是明确例子，但该6图不是最终排除清单。

先不看H、β或模型效果，使用食品名、图像、参考营养审核可接受配对，形成侧表和共同合格子集S_P。正式主分析的V/T/P均在S_P上使用相同训练／测试图片。全568图V/T作为覆盖率补充，独立重拟合；不能把全样本T/V与子集T/P直接拼成同一效应。

建议预固定5个P置换实现；每个实现的配对、种子、实际差值和覆盖率完整保存。P来源数字来自参考库，不按H或β排序，无法合理改动的图片不强配。匹配相容组不等同于交叉验证食品组：前者定义数字候选，后者防同名／近重复图跨折。

**P有5次实现意味着V＋T＋5P，共7组实际输入，而非只做3次前向。** 结果平均各P实现的预测误差，不先平均P预测形成集成优势；P不是5个独立实验样本。合格子集和置换尚未生成。

### 提示可比性

T/P使用相同文字、字段、位置、单位和显示精度，只变数字；核对数字分词长度，尽可能匹配长度并记录无法匹配的情况。各条件固定问题及评分目标，不诱导“看到标签的人会给多少分”。V与T的差异仍包含新增文字、长度及位置效应，所以必须同时看T/P。

P审查只能降低明显不合理性，不能保证完全排除食品—数字不一致带来的惊讶。因此T/P称“相对预定义错配控制的匹配优势”，不称纯粹营养真值因果效应。

## 3. Qwen接口：已核实与待验证分开

本轮读取[官方config](https://huggingface.co/Qwen/Qwen3.5-9B/raw/main/config.json)和[模型卡](https://huggingface.co/Qwen/Qwen3.5-9B/blob/main/README.md)：32语言层、4096隐藏维、27视觉层；语言层按3个linear-attention/Gated DeltaNet＋1个full-attention重复8次。全注意力层为4、8、12、16、20、24、28、32。图中必须标出block类型，不将每四层的起伏解释成价值构建周期。

[Transformers官方文档](https://huggingface.co/docs/transformers/model_doc/qwen3_5)说明可返回hidden_states；模型卡提供enable_thinking=False。**接口支持不等于本地提取已经验证**。正式冻结还需核对：

- 实际模板关闭thinking后，答案前缀和最终非padding位置是什么；不用生成一串解释后的token作为主表征。
- 每个block之后、最终norm之前的残差流是否被一致采集；不要把某接口的最后一项norm后状态混入其他norm前层。最后norm后状态另存，embedding不计入32层。
- 每图／条件独立上下文，清理KV与线性注意力状态，不跨图片沿用缓存；固定视觉分辨率、模板、位置处理、批大小和推理精度。
- 合法答案1、2、3、4在实际答案前缀下是否均可用一个token表示。满足时直接读取同一次前向的四项logit并归一化，同时记录合法概率总质量；否则需冻结序列概率规则，不能继续声称只用一次前向完整得到四个答案概率。
- 模型eval模式，关闭梯度，不抽样；数值可复现性仍需检查计算内核和硬件，而非因“不抽样”就保证位级一致。

工作稿优先BF16，不以4-bit量化作为主表征来源。服务器已有48GB级GPU的历史记录，但当前显存占用、软件兼容及实际峰值未重测。仅保存单token各层：若按33检查点、568图、7组输入计算，BF16约1.00GiB、FP32约2.00GiB；这是激活缓存估算，不是模型加载显存。记录checkpoint revision与依赖，不把metadata中的版本字符串当作安装验证。

## 4. RQ1：冻结V读出，检验条件引起的预测移动

第l层原始向量为h_l^c，c∈{V,T,P_k}。每个外层训练折，仅用其V表征拟合逐维标准化S_l和ridge：

`q_l^c = a_l + w_lᵀ S_l(h_l^c)`。

S_l、a_l、w_l、λ选择全部只依赖允许的V训练图片及H。冻结后直接用于测试V/T/P；**不对T/P重新居中、标准化、校准、截断分数或选择λ**。否则“固定方向”仍可能被预处理改变。

沿用统一ridge约束：损失为平均平方误差＋λ||w||²、截距不惩罚；候选λ为10的−6至6次方共13项，平局取较大λ。所有层共享折与网格，不按层增减PCA／换读出位置。正式冻结前确认该建议，不按外层结果扩网格。

主要误差差值定义为：

```text
G_l^H = MSE(q_l^V, H) − MSE(q_l^T, H)
S_l^H = 平均_k MSE(q_l^Pk, H) − MSE(q_l^T, H)
```

正数表示T较好。G衡量增加对应信息后的净改善；S衡量相对错配的优势。只有S阳性而G不阳性，可能只是P有害，不能称T改善原始看图预测。

冻结线性读出的变化确实满足 `Δq=wᵀ[S(h_T)−S(h_V)]`。但“误差变小”可以来自均值／尺度变化，并不要求每个食品都朝正确方向移动。逐图配对误差、校准偏移、排序变化和原始Δq作为解释性图，不以hidden距离范数定义价值增益。

### 必要的简单基线

同时记录原始评分期望及四项概率。仅用训练V拟合的标量校准和概率线性读出可用于V/T/P输出变化对照，所有参数同样冻结。

另设一个预定的次要行为增量检验，防止把“多了热量数字”自动称为VLM整合优势：

```text
A0：H ~ C + 正确N + p_V + q_l^V
AT：A0 + q_l^T
AP：A0 + q_l^Pk
```

这里C=red、green、blue、object_size、log1p(grams_total)，N=kcal_100g，p_V取三个独立概率分量；各条件都放正确N。训练q必须按第6节的无自身食品标签交叉拟合生成，再用低维OLS和相同测试图片比较。该次要结果只能支持超过指定线性基线，不识别营养整合机制。

## 5. 食品泛化与采集块：保留两种边界

主外层建议为全局5折食品组：同名／近重复组不跨折；所有参与者、条件和层共用测试组。外层测试组的H和β不得出现在任何上游监督训练、校准、调参、P效果筛选或脑回归中。冻结的模型特征和独立元数据可以提前生成；前向见过图片不等于监督映射已用其目标训练。

主行为内层4折食品组，选V的λ。主脑模型逐人训练于训练食品、测试于同一人的未见食品。因此主结论是“个体内学得的映射对未见食品组的预测”，**不是同一映射直接预测新参与者**。上游H排除目标人，也不等于脑LOSO，因为脑系数仍使用该人的训练β。

食品折会把同一个run的不同试次分到训练／测试。LSA的同run估计误差可能相关，食品留出不会自动消除这类依赖。主分析可在脑低维模型加入共享run截距（只从该run训练食品估计），但它不能取代采集块独立性检查。

**预定必要稳健性检查：食品组×session同时留出。** 对每个食品外层折和每个测试session，脑训练只用其他session中的训练食品，脑测试只用该session中的测试食品；上游H仍排除目标人及测试食品组。全组合使每个有效试次只在对应组合测试一次。该检查不使用无法在新session估计的测试run截距，以训练集全局截距及相同内容控制预测，不用测试β居中。先检查sub-016不平衡结构及每折剩余量，不补造数据。

这项检查隔离采集块而不新增“新人泛化”主问题。若主食品结果只在同run混合下出现，必须报告其采集依赖性；不能称为已在独立采集中验证。LOSO和新人×新食品的群体脑映射暂缓。

## 6. RQ2：由wanting读出连接vmPFC，恢复两阶段交叉拟合

### 6.1 关键修订

v03脑端使用原始h，可以省去上游wanting预测；v04把q作为脑预测器，**必须恢复上游标签隔离及训练q的交叉拟合**。只排除目标人的评分仍不足以避免训练q过拟合自己食品的H。

对目标被试s、每个外层食品折，设A为训练食品、T为测试食品：

1. 从其他28人的有效评分构造H_{−s}；s的所有评分都不参与该分支。测试食品组T在其他人的评分也全部排除于训练。
2. 将A按食品组分成4个交叉拟合子折。对其中一折J，仅用A\J的V表征和H_{−s}学习S、a、w；其λ在A\J内再次建议用3折组验证选择，不能用J的H调参。
3. 冻结该V读出器，为J生成q^V/q^T/q^Pk。遍历J，使每个脑训练食品的q都没有使用其自身食品组的H；三条件来自同一个V读出器。
4. 用A的交叉拟合q和目标s的训练β，分别拟合下列低维脑模型。它们用OLS，没有脑端额外λ或层筛选。
5. 用全部A重新训练V欲求读出器，λ仍由A内部选择，为外层T生成三条件q；冻结脑系数后预测T的β。

训练q来自较小交叉拟合训练集，测试q来自A全量重拟合，可能产生尺度差异；保存两者分布与学习稳定性诊断，不用测试H或β再校准。所有层共用完全相同的这一流程。

### 6.2 脑模型与对比

ROI候选沿用独立vmPFC中心[-2,40,-6]、半径8mm，先审计覆盖及单试次质量；旧QC标签不自动剔除。B为ROI平均β，主模型为：

```text
B0：B_s ~ C + 正确N + p_V + 允许的run截距
B_l^V：B0 + q_l^V
B_l^T：B0 + q_l^T
B_l^Pk：B0 + q_l^Pk
```

C/N/p_V与第4节一致；截距与低维系数各模型仅在训练数据估计。所有模型使用相同训练／测试试次，P逐实现拟合后平均误差。脑质量排除不改写29人行为口径。

```text
G_l^B = MSE(B_l^V) − MSE(B_l^T)
S_l^B = 平均_k MSE(B_l^Pk) − MSE(B_l^T)
```

报告B_l^T相对B0的增量作为支持性检查：T优于V/P但仍差于B0，不能说它提供了有用的基线外脑信息。正确N在所有模型内，避免只因T搬入原始热量就把它称为独有神经贡献。

这里**冻结的是V→wanting读出器，脑系数仍分别训练**；不能称整条脑映射都被冻结。由于脑模型有独立截距／斜率，若T只使q发生可逆仿射变化，低维OLS可吸收它，脑预测未必改善。因此行为与脑结果不一致可以合理发生，不必编造隐式价值机制。报告q的脑系数方向；脑预测更好并不自动表示更强正向价值信号。

## 7. RQ3：增益随深度变化，避免追逐“首个显著层”

主要呈现四条差值曲线G_l^H、S_l^H、G_l^B、S_l^B，并提供V/T/P原始性能作为背景。使用同样的层编号和标注的block类型，不能将两端量纲不同的误差直接相减。

为避免从32层挑一个最有利结果，工作稿建议：**四项确认性汇总是各自32层的等权平均误差增益**。这是对预指定深度集合的平均效应，不是先平均各层预测形成集成模型。层不是独立样本。

深度定位用整条曲线及同时区间；辅助按预定四个8层窗口汇总，每窗均有6个线性注意力层和2个全注意力层。窗口不按观察到的峰重画。逐层max或“第一个p<0.05”的层号仅能作探索，不能称为营养价值信息首次出现的时刻。平均效应不阳性但局部曲线有信号时，按经校正的局部证据报告，不换主指标。

### 不确定性与正式冻结要求

- 四项确认性平均增益构成一个检验家族，建议使用Bonferroni调整的双侧98.75%区间，并给95%估计区间；G与S必须分别报告，不能用“一个显著、另一个不显著”代替直接差值。
- 行为区间按食品组重采样，重做标准化、V读出调参及必要交叉拟合；保持重复食品组同折。首先条件于当前29人均分目标。
- 脑端先在每人合并所有留出误差，再参与者等权汇总。因为不同人的q共享上游评分，参与者重采样需重建H_{−s}与完整两阶段拟合，目标身份的所有重采样副本都排除于自身上游训练，不能直接对29个Δ做普通独立t检验。
- 层曲线区间须保留层、条件和P实现的依赖；建议按端点做max-standardized同时带，每端分配2.5%错误率覆盖其两条32层曲线。正式实现需用与食品／run结构相符的无信号模拟验证覆盖率，不能以原始逐层p值画星号。
- 单纯跨人区间条件于这套刺激，并不自动支持食品总体的统计外推；留出食品预测与跨食品总体显著性是不同问题。更广的双因素推断须另验证，不能直接套用朴素双因素bootstrap。

上述推断算法、重复次数和模拟验收尚未冻结；未验证时可以产出描述性曲线和效应估计，不对主假设宣布确认性显著。本轮没有模拟或真实结果。

## 8. 次要诊断与解释边界

**次要行为诊断**：各条件独立训练ridge，使用相同层、折、容量和调参预算；用于检验“若允许重新学习线性映射，T是否更易预测H”。它不取代固定读出的主问题，也不能把性能称为全部信息量。

| 观察 | 合理解释 |
|---|---|
| 固定读出T优于V且优于P | 正确参考信息在既定V读出和预处理下改善了未见食品的预测 |
| 只有各条件独立读出改善 | 与重新拟合后可利用性提高相容；也可能涉及分布、尺度、正则化，不足以证明编码重组 |
| T优于P但不优于V | 可能主要是错配有害，未证明营养提升原始预测 |
| wanting改善、脑不改善 | 行为方向有用，但神经增量未确立；可能与尺度、噪声、基线冗余有关 |
| 只在同run食品留出有效 | 尚未排除采集内依赖，不能声称跨采集稳健 |
| 所有条件均无稳定改善 | 当前模型、任务、参考营养及读出范围内未获证据，不证明模型内部没有相关信息 |

任意高维h→vmPFC、LOSO脑映射、第二架构复现保留为后续可单独提出的扩展，不作为本轮主结果阴性后的救援流程。也不使用hidden距离变大、峰值重合或模型层序来推断人脑时间与因果机制。
