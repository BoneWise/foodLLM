# RSA适用性与MSE后续路线：讨论建议

日期：2026-09-16。本文回应条件性方法讨论；**没有更改主分析、折号、ROI、距离或统计参数，没有运行RSA**。RSA仍为建议分支，当前正式入口继续使用food主分析与food×session稳健性检查。

## 1. 本轮核实的数据结构

- 29人，每人均有ses-01、ses-02、ses-03三个session。上一轮使用两个session讲解只是示例，真实数据是三个。
- 15,869条行为记录中，没有重复的subject×image；每人每图最多一次。脑分析排除两条截断试次，行为保留。
- 主样本493图、13,765条脑观测；每人401–493张有效脑图片，每张图有25–29人的有效观测。全29人共有154张有效图；不建议仅为矩阵齐整默认缩到154图。
- 既有食品组五折主样本图片数98/98/97/99/101。
- 每个提示/层的food×session脑验证为29人×5食品折×3session，共435个划分单元，全部训练及测试非空；主样本每单元训练180–278条、测试12–43条。不要把这些测试单元或其中的图像对当作独立参与者。

## 2. 现有划分能支持什么RSA

### 固定、无拟合的逐层RSA：可以开始，但需补充多体素数据与质量评估

固定ROI、读出位置、距离和RDM比较方法，逐人以有效图构造脑RDM，并截取模型/行为RDM的相同图片。V/T/P用同一人的同一有效图片对；排除试次只作用于该参与者。以493图主样本为共同框架，568图仅作独立V/T补充。

此时没有训练模型或择层步骤，不必为了形式而强制训练/测试五折。全部固定层可评估，但比较32层需要相应不确定性与多重比较处理；不能择最大相关后当作独立验证。

### 含模型选择或参数拟合的RSA：可以继承食品组五折

若选择层、距离、PCA维数、特征权重或控制模型参数，应在外层训练食品中选择/拟合，内层调参，再评价测试食品。保守的未见食品测试只使用两端均为测试食品的RDM元素；不能随机拆分RDM单元，否则同一图片会同时出现在训练和测试的许多图像对中。

如果主张泛化到新参与者，还需相应参与者留出或主体层面的独立评估设计；仅有食品五折不能提供这一保证。

### 单图、被试内crossnobis：当前不满足标准独立重复要求

食品留出和重复测量留出不是同一种交叉验证。crossnobis需要对同一刺激/条件的模式差异获得独立重复估计。三个session放的是不同图片，不能将它们当成同一张图片的三次重复；换折号无法补出缺少的测量。

按食品类别或食品组聚合不同图像后可能研究另一种条件层级，但那会改变研究问题，不能直接称为单图crossnobis。不要通过复制β、拆体素或拆同一次trial来声称获得标准独立重复。

参考：[rsatoolbox距离说明](https://rsatoolbox.readthedocs.io/en/stable/distances.html)。

## 3. 建议RSA起步路线（尚未锁定）

1. 从既有valuation单试次β图提取每人固定vmPFC支持集内的多体素模式；保留既有脑剔除规则与图片身份。
2. 先评估体素有限性/方差、run/session结构与跨人的共同表征一致性。跨人RDM一致性或噪声上限不等于个人重测可靠性。
3. 为首次描述性分析事先指定一套距离与RDM比较：例如脑/模型采用相关距离、RDM用Spearman比较；该组合是候选，不是已确定主方法。相关距离关注模式形状，会去掉模式空间均值，其结果不能替代ROI平均反应问题。
4. 保留run/session标签，检查同run、跨run、跨session图片对的结构与结果敏感性；这些限制性检查不能把普通距离变成无偏crossnobis，也不能自动消除单试次估计噪声。
5. 比较模型—脑、模型—wanting、wanting—脑三种对应；视觉属性、食品类别、能量密度等替代解释另作明确控制。模型—脑相似本身不足以证明价值特异性。
6. 以参与者及食品组/刺激为推断单位，考虑图像对依赖；置换须尊重交换性和采集结构，不能把RDM上三角元素当独立观测。若要求新人与新食品共同泛化，需适配双因素推断并验证，而非照搬独立样本检验。

方法依据：[Schütt等，2023](https://elifesciences.org/articles/82566)。当前RSA不能提供全新盲态独立验证；脑和模型数据已有分析结果可见。

## 4. 继续MSE：建议的实施顺序

### 已完成，不需重复

Qwen A/B全量特征、主493图与补充568图、32层全部交叉验证、两条脑试次剔除后的重拟合及各层点估计已完成。当前food仍为主、food×session为稳健性。固定模型/提示/ROI/样本/折号/基线/32层等权摘要。

### 下一步一：评估脑目标能支持什么解释

整理既有本人wanting与他人均分的脑正对照。主A完整基线下，本人wanting的主样本MSE改善仅约0.0032%，跨session约−0.2325%；均为已有描述性估计，不是新结果。该诊断提示ROI平均β的增量价值信号较弱，但不是理论性能上限，也不能推出不存在多体素价值信息。

继续评估测量质量和估计精度；不按模型增益择ROI/筛人。任何新的QC规则都需独立记录依据、标注事后制定并保留当前版本。先说明限制，再决定神经证据能承载多强的结论。

### 下一步二：实现并验证完整重拟合统计推断

- 行为：按食品组重采样，保留原身份组边界，每次重新训练标准化/岭回归、调参并生成留出预测。相同食品的重采样副本不能跨训练/测试。
- 脑：现有目标是以刺激集为条件的参与者层面推断。按参与者重采样时，重建H−s，排除目标原始身份的全部副本，重新进行上游交叉拟合与脑回归；共享行为训练导致参与者统计量相关，不能仅bootstrap现成29个差值。
- 先用保留缺失、食品组、共享人类目标等结构的模拟检验零效应/已知效应下的误报与区间覆盖，再确定重采样次数和区间配置。原配置中的候选区间参数不能自动视为已验证。
- 若新增“新参与者且新食品”的联合泛化主张，需要另行设计联合推断，不能把仅参与者重采样的区间解释为双重泛化。

缓存的模型隐藏状态可以复用，不需重新运行Qwen；统计模型在每次重采样中重拟合。具体区间、次数、接受标准仍未锁定；这是结果已可见后的方法完善。

### 下一步三：形成完整结果判断

保留A的四项跨32层主摘要：行为T−V优势、行为T−P优势、脑T−V优势、脑T−P优势（均按既定误差差定义，正值有利于T）。同时报告T相对共同脑基线的次要增益、food×session、B和全568图V/T补充。

报告效应大小、适当区间、全层曲线与方向；不以最优层、最优提示或新增门槛替换主摘要。T稍好于V/P但仍不及共同基线，不能表述为额外神经预测价值成立；区间宽或测量弱时应保留不确定性，不能直接断言等效或无机制。

## 5. 如需新的数据收集

完成当前MSE分析不要求马上新增实验。如果目标转向更强的单图RSA，应在新采集中让同一图片在多个独立run/session重复呈现，优化单试次设计并评估模式可靠性。如果目标是人类营养整合机制，则还需人类V/T/P标签操纵及适当随机化/平衡；现有人类仅看图的数据无法识别标签对人类的因果效应。这两类新采集目标不同，不能由更换MSE/RSA指标代替。

**当前建议：先完成现有MSE的测量解释与推断验证，同时将RSA作为明确标注的可行性分支。是否升级RSA为主分析留待研究问题与测量质量评估后决定，不因哪一种方法更容易得到正结果而切换。**
