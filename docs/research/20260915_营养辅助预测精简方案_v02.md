# 营养辅助食物欲求预测：精简实验方案 v02

日期：2026-09-15。根据[最新送评意见](inputs/20260915_用户提供_营养方案精简意见.txt)和[现有数据核对](20260915_现有数据与精简方案对照.md)修订。**这是本轮形成的工作草案，不是已经预注册或运行的实验。** 历史方案保留，但当前建议入口以本版为准。

## 1. 一个研究问题

> 向冻结的多模态模型提供与食品图片正确匹配的参考能量密度，能否改善它对原始仅看图人类欲求的预测？这种新增预测信息是否延伸到vmPFC反应？

这是营养辅助预测。模型获得实验现场人类未见的侧信息；阳性不证明人类营养标签效应、模型营养纠错或人类式整合机制。能量密度有图片—价值—vmPFC相关研究作为理论起点，但文献不保证提示实验阳性。[Tang et al., 2014](https://pubmed.ncbi.nlm.nih.gov/25304885/)

## 2. 本版只保留什么

| 项目 | v02工作方案 |
|---|---|
| 人类目标 | 当前29人对568图的1–4分想吃程度；已有逐图均分 |
| 营养 | **能量密度 `kcal_100g`，kcal/100g**；本版采用它为唯一主属性，不再筛选赢家 |
| 模型 | 一个冻结VLM，版本待选；只收集输出，不提取hidden state |
| 输入 | V图片、T图片＋对应能量密度、P图片＋合理错配能量密度 |
| 输出 | 预定义1–4合法答案概率的期望评分；记录原始答案及有效概率质量 |
| 行为校准 | 每外层训练折仅在V拟合一个共同线性校准，冻结后应用V/T/P |
| 脑目标 | 一个独立vmPFC球形ROI的平均单试次反应，定义候选为[-2,40,-6]、半径8mm |
| 主要指标 | 同一测试观察上的MSE差；Spearman与误差图为辅助 |
| 当前移出 | I、E、自身营养估计、反事实梯度、多营养、fat×carb、隐藏层、全脑、RSA、机制性残差检验 |

模型仍预测原人类的仅看图任务，不能把T问题改成“人看到能量标签后有多想吃”。各条件独立上下文、共同提示和相同图像处理。使用中性数字说明，不出现高热量、健康或不健康等标签。

## 3. P只做一个控制类型，但先解决数据匹配

P从不看行为／脑结果的食品相容分组中置换能量值，保留字段、单位、位置和数值精度。现有大类太粗，且部分图缺少加工标记；需要一张新的配对侧表，不能直接使用全局随机交换。

建议预先固定5个P置换实现。它们是同一种控制的重复实现，不是新增5项研究问题。逐实现拟合／计算误差后，**平均误差**作为P结果，不先平均输出制造额外的集成模型优势。正式配对表与种子尚未生成。

V/T可在568图上进行；T/P主比较限于配对审查合格的共同子集S_P，并在S_P同时报告T/V。最终“正确匹配有帮助”的联合结论限定于S_P。无法合理错配的图保留在全样本V/T分析，不以荒谬数字凑齐P，也不根据模型效果筛选S_P。

多次P的候选来源、数值变化幅度、实际未改变输入和配对覆盖率均需保存。即使经过审查，T/P仍可能同时反映数值对应性和食品—数字一致性，解释不能越过该边界。

## 4. 行为分析：同一校准，两个层次

### 4.1 主要问题：信息是否让预测变好？

记原始模型期望分为M_V、M_T、M_P，人类均分为H。五折按规范化食品名称成组；当前79组同名食品涉及217张图，分组防止其任意跨折，但不能宣称已排除所有视觉近重复。

每折仅在训练图拟合 `f(M_V)=a+bM_V`，应用于该折测试V/T/P。预定保持评分方向的非负斜率；若校准退化为常数，标记为该映射无法区分条件，原始评分结果照常报告，不能由此断言营养信息无用。主校准不作条件分别拟合，也不按测试结果更换函数或截断规则。

主要对比：

```text
全样本信息增益：MSE[f(M_V)] − MSE[f(M_T)]
匹配特异性：   平均_k MSE[f(M_Pk)] − MSE[f(M_T)]，在S_P
```

S_P上的T/V作为匹配特异性联合判读的一部分。同一f下的变化才用于描述输入操作后的评分移动；各条件最佳校准不属于本版主要实验。正斜率线性校准不改变排序，Spearman不替代MSE主检验。

### 4.2 关键增量：是否超过直接使用营养数值？

对H拟合三个低维模型，**这里直接使用原始M，不先使用人类校准值**：

```text
F1：H ~ Z + M_V + N
FT：H ~ Z + M_V + N + M_T
FP：H ~ Z + M_V + N + M_Pk
```

N均为对应图片的正确参考能量密度，FP也不例外。Z固定为已有且完整的 `log1p(grams_total)`、`intensity_norm`、`object_size`；包含截距。对所有比较使用同一训练和测试观察。FT/FP在S_P比较；对应的F1也在相同数据上重拟合，避免混淆样本变化。

采用普通线性回归，不引入ridge、样条或自动基线选择。训练折完成标准化和秩检查，秩退化使用预定的最小二乘解并报告；若M_T落在基线张成空间，不能声称存在新增线性信息。主检验FT相对F1的测试误差降低，以及FT相对FP的优势。

这些结果只表明超过指定线性组合。非线性机制不属于本版结论，因此不为该机制增加一组主检验。

## 5. 脑验证：使用原始模型输出，省去上游人类训练

这里是对送评意见的进一步简化：**脑模型不需要使用共同人类校准后的分数。** 原始输出、N、Z均不含人类评分训练结果，可以直接进入逐被试脑回归。

```text
F1_s：B_s ~ Z + M_V + N
FT_s：B_s ~ Z + M_V + N + M_T
FP_s：B_s ~ Z + M_V + N + M_Pk
```

一个固定的非零斜率仿射校准，在含截距的无惩罚线性回归里并不增加预测信息。直接用原始M可避免将行为折相关的人类标签重新引入脑分析，也无需先前复杂的上游交叉拟合。**仅共享一个校准器本身并不保证消除泄漏；删除该上游监督步骤才是本版的简化依据。**

每位参与者按完整run留出，现有29人共346个run；所有脑系数和预处理拟合仅用训练run。sub-016按实际10个run处理，不补造数据。独立ROI及固定体素支持集不从模型阳性图中选择；必要的采集质量处理先审计，不能用当前脑结果反选规则。

每人汇总留出有效试次上的MSE，形成FT相对F1的ΔMSE_s及FT相对平均FP误差的差值；所有对比使用一致试次。参与者层面等权汇总并报告配对区间，试次和run不充当独立参与者。由于β尺度和信号质量可能不同，辅助报告逐人标准化增量及个体分布。

群体不确定性首先条件于这套刺激和已固定预测器；仅跨被试检验不能自动支持刺激总体上的显著性外推。欲主张跨刺激总体，需要另行验证被试与刺激双因素推断，本版不把复杂推断方法作为额外研究方向。测试run中的未见图片预测仍正常报告。

FT优于F1但不优于FP：有神经增量，尚未证实正确数值对应性优于错配。只有脑端直接FT/FP比较支持，才把匹配优势延伸至脑。原始神经残差图仅作可视化。

## 6. 统计判读与实施边界

- 两项主要行为对比、两项行为增量比较及两项神经扩展比较，按预定检验家族处理多重比较；全部报告效应与区间。神经为次要扩展，不将行为阳性当作选择ROI或参数的依据。
- 行为不确定性以食品名称组为抽样单位；重采样时重新拟合共同校准及低维模型，重复实例保持同组／同折，不能对五个fold分数做普通独立样本检验。主行为目标是当前群体平均，外推更广人群需另估人群抽样不确定性。
- 冻结模型可一次生成所有条件输出；数值字段和P配对不依赖人类／脑标签。提示、模型和属性不能在测试表现上选优。
- 不把脑增量阴性解释成模型已解释全部人类价值；不把脑改善而评分不改善称为无意识价值通路。
- 本轮确认数据结构和文件可用性，没有确认ROI质量或最小可检出效应。

## 7. 开始正式实验前只剩三类准备

1. **任务／模型接口**：选一个冻结检查点，核对日文原始标签，验证合法答案概率、图像处理和评分方向，冻结prompt。
2. **P与划分**：不看结果审核相容分组，冻结S_P、5个置换、种子和名称成组fold，保存源文件哈希。
3. **脑入口**：按独立坐标生成ROI，审计功能覆盖、缺失值、单试次稳定性与旧QC标记，冻结新脑质量规则后提取反应。不把旧“exclude”标签自动套到行为或新脑分析。

随后只执行：**V/T/P输出 → 共同校准与行为增量 → 原始输出的vmPFC增量验证**。本版不安排隐藏层或其他营养实验。
