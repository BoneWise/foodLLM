# foodLLM

[English](README.md)

研究视觉与视觉—语言模型的食物表征：预测未见食品上的个人评分偏离，并比较模型表征与人类 fMRI 反应。

**更新：2026-10-24 · 最新修订分析已完成**

## 研究设置

比较 Qwen3.5-9B、CLIP 和 DINOv2，使用 29 人、562 张食物图片、15,702 条评分和五折食品组留出评价。个人目标为本人评分减去同一图片可用他人的评分均值；预处理和模型选择均限制在训练数据内。

## 主要结果

- 在训练数据内选择读出后，Qwen、CLIP、DINOv2 的个人偏离预测相关分别为 **0.454、0.435、0.429**；联合视觉基线加入 Qwen 的 MSE 收益为 **0.00938**。固定 R0 下三者约为 0.423–0.426，比较结论依赖读出配置。
- 控制量尺基线后，Qwen 偏相关为 **0.418**；相对 CLIP、DINOv2 的配对差为 **0.0197 [0.0060, 0.0344]**、**0.0233 [0.0082, 0.0394]**，方括号为条件 95% bootstrap 区间。
- 同一 Qwen 模型中，加入语言模型加工后表征，在指定参照下提高留出脑预测。高级视觉条件增量为 **ΔR² = 0.01090**；另行采用共同 SST 分解时，区域均值项占两项总改善的 **81.44%**。该百分比不能直接作为原逐体素平均 ΔR² 的组成比例。

这些结论限于指定数据和读出下的预测。行为与脑收益分别测得，不能据此建立同一机制、语言因果贡献或区域优越性。
