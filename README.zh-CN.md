# foodLLM

[English](README.md)

本项目研究视觉与视觉—语言模型的食物表征、个人评分的留出预测，以及这些表征与人类 fMRI 反应的关系。

## 最新进展 · 2026-10-24

新增分析使用 **29 人、562 张食物图片、15,702 条评分**，在食品组留出条件下比较 Qwen3.5-9B、CLIP 和 DINOv2。完整行为数据仍为 568 图、15,869 条评分；共同分析集排除六张纤维缺失图。

在训练数据内选择读出后，Qwen 对个人评分偏离的预测相关为 **0.454**，CLIP 为 **0.435**，DINOv2 为 **0.429**；在联合视觉基线上加入 Qwen 的平均 MSE 收益为 **0.00938**。这一优势依赖读出配置：固定 R0 下三模型的相关约为 0.423–0.426。

同一 Qwen 模型经语言模型加工后的表征，在指定参照下也提供额外的留出脑预测信息。行为收益与脑预测收益是分别测得的，尚不能确认为同一机制，也不识别语言因果贡献或区域优越性。本次公开更新提供汇总结果及条件 bootstrap 区间；新阶段训练流程和预测数组仍留在研究环境。

## 早期营养条件 RSA · 2026 年 9 月

早期阶段考察：向模型提供营养信息后，其食物表征与人类 fMRI 表征的对应关系如何变化？研究使用 Qwen3.5-9B 的逐层隐藏表征，通过表征相似性分析（RSA）比较图片基线、匹配营养、无关文本和错配营养四类输入。

该阶段 RSA 分析覆盖 **29 名参与者、401 张食物图片、32 个模型层和 41 个脑区**，包含两种提示措辞，以及蛋白质、脂肪、碳水化合物和纤维四种营养属性。OFC、vmPFC、视觉区域与随机抽取的 HCP 分区共同用于比较变化的区域分布。

### RSA 结果

描述性结果显示，对齐变化随营养、脑区、层和提示而变化。蛋白质与脂肪在多个前额叶区域呈现相对图片基线的正向均值变化；碳水化合物与纤维呈现不同的区域模式。正确匹配与错配营养之间的差异，需要结合图片基线和无关文本条件共同解释。
