# 多营养 × OFC/vmPFC：A/B完成后的综合解读

2026-09-17。四种单营养实验与既有kcal的OFC扩展均已完成描述性RSA。**A仍是主提示，B仅检验措辞稳健性；没有显著性检验或置信区间。**

## 已完成的实验

| 项目 | 实际执行 |
|---|---|
| 新营养 | 蛋白质、脂肪、碳水化合物、膳食纤维；每次只给一个g/100 g字段 |
| 模型 | Qwen3.5-9B；thinking关闭；32层固定pre-answer token |
| 条件 | V共用；每营养T与P1–P5；A主/B稳健性 |
| 样本 | 401张共同食品、29人；每ROI 11,207条有效脑试次；11,209条行为评分 |
| 脑区 | Suzuki原AAL解剖lOFC、mOFC，以及原vmPFC |
| 方法 | raw trial β；1−Pearson RDM；RDM间Spearman；P先各算RSA再平均 |
| 运行量 | 新增19,248个模型输入；155,904个逐人神经RSA分数 |

401图由四属性共同可错配的元数据条件决定，保留25/40个食品形态组。保守错配阈值是助手在运行前说明的实施默认值，未收到用户明确选择；它没有经过人类可信度验证。原493图kcal实验独立保留，不能把两种样本的效应直接用于营养强弱排名。

## 目前支持怎样的描述

**部分营养—脑区组合出现跨提示词同向的相对增益，但没有普遍、跨脑区且同时符合wanting的正确信息优势。**以下归纳只描述本批曲线，不是从全部比较中筛出的确认性发现；全部12组比较都在[完整结果](结果摘要.md)中展示。

- **蛋白质 × lOFC/vmPFC**：A/B的跨层T−V和T−P均值都为正，T−P在绝大多数层为正。lOFC的T−P跨层均值A为+0.000481、B为+0.000384；vmPFC为+0.000227/+0.000355。
- **纤维 × mOFC**：A/B两对比跨层均值均正，但T−P从A的+0.000957降到B的+0.000144，幅度依赖措辞。
- **脂肪**：三个ROI的T−V跨层均值在A/B均正，但vmPFC的T−P均为负，OFC的T−P跨层均值随提示改变符号。加信息的优势不能归结为正确数值匹配。
- **碳水**：lOFC的T−V跨层均值在A/B均负；mOFC和vmPFC虽T−V均值为正，T−P却均负。没有跨提示一致满足两个对比的ROI。
- **纤维的其他ROI**：lOFC是T−P均值正、T−V均值负；vmPFC的T−P由A正转为B负（B全部32层负）。不能称跨脑区稳定提升。

正差值不等于强的绝对脑对齐。例如蛋白质vmPFC的T跨层平均ρ仍为A −0.000414、B −0.001319；纤维mOFC也仍为负。必须同时看V/T/P绝对曲线，不能只看差值图。

## Wanting没有给出一致的正确匹配优势

A中四种营养的T跨层平均wanting RSA全部低于V。B中蛋白质T高于V（0.194640 vs 0.185382），但P更高（0.198137）；脂肪、碳水、纤维的T跨层平均仍低于V。因此不能把部分神经差值概括成模型更接近人类food-wanting表征。

这是群体图片均分RDM的固定参照，不能当作29份独立行为RSA样本。跨层均值仅帮助阅读，完整逐层曲线保留。

## 个体差异与测量限制

蛋白质lOFC的T−P群体均值在A有30/32层为正，但逐人跨层差值仅15/29人为正，B为18/29；纤维mOFC对应20/29和15/29。层高度相关，正向层多不能替代participant统计。

当前401图的session/run脑RDM相关均值约为lOFC 0.161/0.240、mOFC 0.079/0.150、vmPFC 0.072/0.153，扫描结构值得在后续敏感性分析中检查。这些QC本身既不能证明模型效应是假象，也不能被忽略。单试次可靠性未解决，mOFC与原vmPFC重叠58体素，三ROI也并非独立样本。

原493图kcal在新增lOFC/mOFC中没有稳定的正确匹配优势；见[OFC kcal独立报告](../20260917_OFC_kcal报告_v02/结果摘要_含逐人分布.md)。
